## 0. 共通規格

| 項目 | 規格 |
|---|---|
| 主螢幕解析度 | 1920×1080 為基準，素材做 2 倍（3840×2160）；四邊 5% 安全範圍（畫面清單 §0） |
| 檔案 | 平面：PNG（含原始分層檔，例如 PSD 或 Krita）；圖示：SVG＋PNG；3D：glTF 2.0 |
| 命名 | `類別_ID_變體@2x.png`，ID 和內容 ID 一致（例如 `card_minor.swords.10@2x.png`、`icon_status.poison.svg`） |
| 佔位 | 灰盒版用文字卡、純色格子、幾何圖示；佔位檔和正式檔同名，換檔不用改程式 |
| 可讀性 | 3 公尺外可辨認；圖示靠形狀區分，不只靠顏色（色盲友善） |
| 交付 | 放 `apps/godot-client/assets/`（主螢幕）與 `apps/mobile-web/public/assets/`（手機）；同一張圖兩端共用時只放一份來源，建置時複製 |

## 6. 製作時程對照

| 時間 | 要交付 |
|---|---|
| M2 結束（約 2027-10，第一次試玩） | 不需要（文字版主螢幕） |
| 風格切片（2026-12-01～約 2027-05-25） | 第 2 節子集的正式版，小黃在 Godot 用假資料組場景；含 1 個職業的骨架動畫 |
| 風格切片通過後（約 2027-05～2029-05） | 卡面插畫量產（51 張）；6 職業模型與骨架綁定（手部動作、擺動）；其餘清單項目 |
| 第二階段 Godot 框架（2028-10～2029-01） | 小黃的場景接上你寫的連線與演出框架；此時至少要有主畫面、翻牌、骰子正式版 |
| M8（約 2029-08～10，灰盒版） | 正式版完成多少用多少，其餘保持佔位 |

- 小黃兼職每週約 20 小時（2026-11-25）。工時先用第 6-1 節的粗估排程，**風格切片完成後由小黃依實際速度回填**，再重排時程（2026-11-25 確認）。小黃擁有 Godot 場景、特效、骨架動畫；你擁有 `Net`、`Store`、`Clock`、`Presenter`、協定類別。分界：場景節點只讀 `Presenter` 給的演出步驟，不直接碰連線。
