# 命運酒館｜機器人策略 v1.0

> 更新日期：2026-11-25（v1.0：定案）
> 用途：① M7b 平衡模擬（第一階段 M7a 只做 `random`）（`tools/simulator`，閘門 G3 依《平衡標準》判定）；② 斷線代打（技術規劃 §12-2）；③ 隨機壓力測試（找卡死）。
> 依據：《設定總表》§4 數值匯率、《平衡標準》v1.0、《技術規劃》§12-2、§12-5。
> ⚠️ ＝模擬後再調的參數。

---

## 1. 機器人種類

| 種類 | 用途 | 決策方式 |
|---|---|---|
| **隨機合法** `random` | 找卡死、找例外（M2-A01、M4-A06、M6-A08） | 從伺服器給的合法選項中，用 `bot` 流平均挑一個 |
| **貪婪** `greedy` | 平衡模擬的主力；斷線代打 | 用「數值匯率」把每個選項換算成金幣價值，挑期望值最高的（第 3 節） |
| **性格變體**（2026-11-25 確認） | 檢查策略多樣性（平衡標準 L1、L3） | 貪婪＋參數：`aggressive`（偏好爆發、攻擊、喝酒換報酬）、`cautious`（偏好穩定、少喝） |

- 斷線代打用 `greedy`，小遊戲固定 40% 勝率（已定案）。

## 2. 共通原則

| 項目 | 規則 |
|---|---|
| 看得到的資訊 | **只看自己手機看得到的**：伺服器用同一個投影函式產生「該玩家的投影」給機器人；看不到別人的手牌、大牌、牌序、聖殿騎士數字（2026-11-25 確認） |
| 決策入口 | 和真人一樣回應 `prompt.request`、送命令；決策以系統命令（來源 `bot`）寫入，重播直接讀紀錄 |
| 亂數 | 只用 `bot` 流（依索引取）；同分選項用它打破平手 |
| 速度 | 每次決策 < 5 毫秒；1,000 局模擬在開發機 ≤ 15 分鐘 |
| 程式位置 | `packages/bots/`（伺服器代打與 `tools/simulator` 共用同一份） |
| 小遊戲（模擬） | 不模擬操作；依參數 `minigameWinRate`（預設 50%）用 `minigame` 流擲；平衡標準 L2 用 60% 測試 |
| 時間估算（模擬） | 以行動數計；換算秒數用設定檔的每階段估計（預設每次行動 60 秒） |

## 3. 貪婪機器人的估值

### 3-1 狀態價值（金幣當量）

```
V = 生命 × 3（生命 ≤ 30 時 × 4.5）
  + 金幣
  + 清醒值% × 2
  + 手牌 × 20（魔術骰子常見 10、稀有 20、魔幻 40；道具用售價）
  + 持有大牌 × 40
  + 路線進度（見 3-3）
  − 已知的負面狀態（中毒剩餘傷害 × 3、入獄 −20…）
死亡時：V = 魂火 × 15 + 冥界道具售價 × 15
```

- 對手受到 1 點傷害或損失，對自己算 **+1/3**（對領先者算 +0.5）。
- 喝 1 杯＝ −6；清醒值 ≤ 15% 時每杯改算 −9（接近清醒反噬）。

### 3-2 選項評估

- 有隨機分支（擲 D8、正逆位）的選項，用機率加權算期望值；擲骰類列舉 1～8 全部結果。
- 只看「這一步」的結果（不往後搜尋多步）；例外見 3-3 路線計畫。
- 風險參數 λ（預設 0＝只看期望值）：`aggressive` λ＝−0.2（偏好波動），`cautious` λ＝+0.3（扣掉標準差的 30%）。

### 3-3 路線計畫（每個「自己的一周」開始時重新決定）

| 條件 | 路線 | 行為差異 |
|---|---|---|
| 金幣＋預估到第 3 周的收入 ≥ 最便宜未售出聖物底價 × 0.8，或職業類別是經濟型 | **經濟路線** | 存錢：購物只買 ≤ 20 金幣的必要道具；拍賣只對聖物出高價 |
| 其他 | **血量路線** | 花錢：優先買攻擊、防禦道具與升級技能 |

- 路線進度價值：經濟路線＝（金幣 ÷ 目標底價）× 100；血量路線＝（自己生命 − 對手平均生命）× 1。

### 3-4 格子價值（擲骰後決定要不要用魔術骰子）

| 格子 | 價值（預設，設定檔可調） |
|---|---|
| 起點（經過） | +30 |
| 酒館 | 依當下醉意的每張期望值（清醒 +0.6、微醺 −1.1、爛醉 −2.8） |
| 試煉之地 | 以小遊戲勝率估算：勝率 × 15 − 敗率 × 10 |
| 神殿 | +40（抽大牌）；死亡時 +30（2 魂火） |
| 商城、煉金工坊 | 有閒錢時 +10，否則 0 |
| 祭壇 | 付得起升級時依升級價值，否則小祈福 +6 |
| 監獄 | −20 |
| 安全區 | +5（被攻擊風險高時 +15） |
| 拍賣行 | 經濟路線且買得起聖物時 +60，否則 +5 |
| 賭場 | −2 |

- 使用魔術骰子的條件：（新落點價值 − 原落點價值）≥ 骰子價值 ＋ 5。

## 4. 各決策點的規則

| 決策點 | 貪婪機器人的做法 |
|---|---|
| 選職業 | 模擬：隨機（平衡要涵蓋全部組合）；代打：不會遇到 |
| 聖殿騎士選數字 | 選讓「停在試煉之地或監獄」機率最低的點數（依目前位置估算）；之後不改 |
| 擲骰前後窗口 | 依 3-4 決定自己的骰子；對別人的擲骰，只在「讓領先者落到監獄，或錯過神殿、拍賣行」時使用 |
| 盲選牌背 | 用 `bot` 流隨機選（沒有資訊可用） |
| 地圖殘頁 | 偷看任一張；期望值 < 0 就移到最底部 |
| 卡牌選項（choose） | 依 3-2 選期望值最高者 |
| 選目標 | 有害效果：綜合資產第一的活人（排除盟友）；有益效果：自己或盟友 |
| 投票 | 投綜合資產第一的人（不投自己） |
| 接受風險、爆發 | λ 決定；預設期望值 > 0 才冒險 |
| 旁觀者下注 | 押勝率較高的一方，金額 10 |
| 反應窗 | 只在「被取消的效果價值 ≥ 15」時使用反應牌或道具 |
| 打出大牌 | 價值 ≥ 30 時打；生命 ≤ 20 而且有防死大牌時優先打；手上超過 2 張時打價值最高的一張 |
| 小技能、大招 | 可用時，價值 ≥ 10 就用（大招 ≥ 25） |
| 使用道具 | 回復類：生命 ≤ 上限的 60% 才用；攻擊、防禦類：在攻防時用價值最高的一個 |
| 商城 | 保留金（經濟路線：目標底價的進度；血量路線：20）以外的錢，買「價值 ÷ 售價」最高、且 > 1.1 的道具 |
| 煉金工坊 | 升級後價值增加 > 費用 × 1.2 才升 |
| 拍賣出價 | 出價上限＝自己對該物品的估值（聖物：經濟路線時＝全部金幣 − 10；非經濟路線＝0）；每次只加最小加價 |
| 賭場 | 下最低注 10；對莊家遊戲選莊家優勢最低的；高低連猜累計 ×2 就停（⚠️ 依高低連猜期望值模擬再調） |
| 賭徒 | 賭徒依技能把注碼提高到上限的 50%，其他照上 |
| 祭壇 | 付得起時升級「每圈價值最高」的技能；付款順序：金幣（留保留金）→ 生命（留 60%）→ 喝酒（清醒值 > 40%）→ 道具 |
| 喝酒二選一 | 照 3-1（喝 1 杯＝ −6，低清醒時 −9） |
| 死亡期間 | 冥界商店：魂火距離門檻 ≥ 3 時才買，優先招魂鈴、幽影步；移動骰優先落在試煉之地或神殿 |
| 致命保護多個 | 選對自己之後價值損失最小的那一個 |
| 喝酒確認 | 不處理（只是現實紀錄） |

## 5. 驗收

| # | 條件 |
|---|---|
| B1 | 隨機合法機器人 1,000 局無例外、無卡死（現有 M2-A01、M4-A06、M6-A08、M7-A01） |
| B2 | 貪婪 1 隻對隨機 3 隻，貪婪勝率 ≥ 45%（平衡標準 L1）；如果達不到，先檢查機器人而不是改遊戲數值 |
| B3 | 封包掃描：機器人拿到的投影和該玩家手機收到的完全相同 |
| B4 | 同種子＋同設定跑兩次，所有決策一致 |
| B5 | 每次決策 < 5 毫秒；1,000 局 ≤ 15 分鐘 |
