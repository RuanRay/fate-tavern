# 命運酒館｜規則優先序 v1.5

> 更新日期：2026-11-25（v1.5：血量判定同分比綜合資產、仍同分並列獲勝；v1.4：有限牌庫與盲選抽牌）；2026-11-24（v1.3：反應窗時限與提前關閉；v1.2：加入祭壇技能升級的限制與死亡歸零、復活狀態、攻防落敗基本懲罰、死亡玩家道具與復活保留道具）
> 以第三方檢核（乙）提供的優先序為基礎，配合目前定案的規則整理。用途：卡牌、職業、星座、道具、聖物、場地、死亡規則互相衝突時的裁定順序，也作為數位版規則引擎的判定依據。
> 核心原則：**勝利與淘汰最高；明確寫出的特例只覆寫它提到的部分；不能自行創造卡面沒寫的例外。**

---

## 1. 總優先序（數字越小越優先）

| 優先級 | 層級 | 內容 | 衝突時 |
|---|---|---|---|
| 0 | 安全與現實限制 | 玩家退出、身體不適、斷線（現實飲酒不設上限） | 永遠優先，不能被遊戲效果取消 |
| 1 | 遊戲結束與勝利判定 | 固定回合結算、聖物繞行完成、大逃殺（其他人同時死亡時的唯一活人） | 合法達成時，**先把整個事件（含後續觸發）結算完，再判定勝利** |
| 2 | 死亡、死神追逐、復活 | 生命歸零、資產清空、魂火、追逐失敗時魂火減半 | 活人的卡牌不能覆寫死亡規則，除非寫明「可對死亡玩家使用」 |
| 3 | 不可覆寫限制 | 數值上下限、單次傷害上限 30、每局／每圈次數、唯一性、「不能使用」條款、祭壇升級上限（每技能最多 Lv2、每次停留最多升 1 次） | 不能被加成、倍率或複製突破 |
| 4 | 替代效果 | 「改為」「取代」「改擲 D6」 | 取代原效果，不同時套用 |
| 5 | 取消與免疫 | 取消卡牌、免疫傷害、免疫負面、安全區 | 取消成功後不再處理被取消的內容；免疫只擋寫明的類型 |
| 6 | 致命保護與承傷轉移 | 免死、替身、代替防守、傷害轉移 | 先決定由誰承受，再判定免疫、減傷、致命保護 |
| 7 | 卡面明寫的特例 | 卡片上直接寫的特殊處理 | 只覆寫它提到的通則 |
| 8 | 聖物效果 | 賢者之石、不老聖杯、永恆之槍 | 高於一般道具、職業、星座；低於明確禁止與卡面特例 |
| 9 | 場地與狀態 | 安全區、監獄、持續封鎖、增益與減益 | 場地限制優先於角色能力 |
| 10 | 職業主動技能 | 小技能、大招 | 不能突破次數與不可覆寫限制 |
| 11 | 道具與魔術骰子 | 主動道具、反應道具、骰子修改 | 只能在合法反應窗使用 |
| 12 | 星座、職業被動 | 常駐加成、條件觸發、陪喝、下毒 | 同時觸發時，由當前玩家決定自己效果的順序 |
| 13 | 塔羅大牌 | 正逆位效果 | 依卡面執行；持續效果進入狀態區 |
| 14 | 試煉卡、塔羅小牌、冥界事件 | 對決、一般事件、醉意版本 | 依卡面順序結算 |
| 15 | 基礎規則 | 移動、配對、喝酒、傷害、金錢、清醒值 | 沒有特例時才適用 |
| 16 | 玩家選擇 | 選目標、平手順序、分配 | 不能創造額外效果 |

## 2. 標準結算流程

### A. 行動開始

| 步驟 | 內容 |
|---|---|
| A1 | 檢查玩家是活人還是死亡玩家（死神追逐中） |
| A2 | 處理「行動開始時」的狀態（中毒、持續回血等） |
| A3 | 檢查是否被暫停、凍結 |
| A4 | 可使用「行動開始時」的技能與道具 |
| A5 | 可以行動的話，進入擲骰與移動 |

- 被暫停的玩家**仍算完成一次行動**，會推進自己的持續狀態與全場回合；但不擲移動骰、不移動、不觸發停留格。
- 只寫「不能移動」的效果，玩家仍可使用技能並處理當前格。
- **額外移動不算行動**，不推進技能冷卻與持續時間；經過起點照常領收入，同一次行動最多領 1 次。

### B. 擲骰與移動

| 步驟 | 內容 |
|---|---|
| B1 | 宣告這次擲骰的用途（移動、對決、事件） |
| B2 | 套用強制替換骰型的效果（例如改擲 D6、D4） |
| B3 | 擲骰前反應窗（巨人骰、侏儒骰、先知骰、封印骰、王權骰等） |
| B4 | 擲骰 |
| B5 | 擲骰後修改窗（每位玩家最多 1 張魔術骰子） |
| B6 | 依序套用：替代骰型 → 指定結果 → 重擲 → 翻轉 → 倍增 → 固定加減 → 上下限 |
| B7 | 鎖定最終點數 |
| B8 | 移動並處理經過的格子（起點收入、惡靈作祟） |
| B9 | 處理停留格 |

### C. 抽牌與卡牌事件

| 步驟 | 內容 |
|---|---|
| C1 | 抽牌：從有限牌庫最上面 4 張牌背盲選 1 張（雙子座、鷹眼、重抽依其規則）；多選一沒採用的牌放回牌庫最底部；牌庫空了先把棄牌堆重洗 |
| C2 | 決定正位或逆位（系統隨機，依醉意階段） |
| C3 | 公開卡牌（偷看類的資訊只給抽牌者） |
| C4 | 選擇目標、模式、押注或是否接受風險 |
| C5 | 卡牌反應窗 |
| C6 | 確認是否被取消 |
| C7 | 擲骰或小遊戲 |
| C8 | 執行傷害、回血、金錢、清醒值、狀態 |
| C9 | 每個子效果結算後檢查死亡（逐項） |
| C10 | 處理後續觸發，直到觸發佇列清空 |
| C11 | 放回牌庫或進入持續狀態區 |
| C12 | **整個事件結算完，檢查勝利** |

- 卡面閱讀順序：限制（不能、只能）→ 目標與條件 → 代價 → 替代或取消 → 主要效果 → 額外效果 → 持續時間 → 次數與結束條件。
- 代價沒付成功，效果不發動；已付的代價不退回，除非取消效果寫明退款。

---

## 3. 同時觸發

1. 當前行動的玩家先排列自己的效果。
2. 其他玩家依回合順序排列自己的效果。
3. 系統、場地、牌庫的效果最後。
4. 逐一結算；**每個效果結算完都檢查死亡；勝利等整個事件（含後續觸發）結算完才判定**，避免一張牌結算到一半對局就結束。

不能由玩家調整順序的：現實安全處理、固定回合結束、生命歸零、無法支付代價、數值上下限、次數用完、卡面已寫明順序。

---

## 4. 反應窗與取消

- **每個事件最多 2 層反應**：第 1 層回應原始效果；第 2 層回應第 1 層；之後不再開新反應窗，從最後一層往前結算。
- 反應大牌（惡魔逆、高塔逆）在別人回合打出時，**直接以反應那一面發動**。
- 多位玩家同時想回應時，依回合順序加入反應鏈。
- 每層反應窗最長 **5 秒**；所有被詢問的人都回應後立即關閉。逾時或選「不使用」＝放棄這一層。被詢問者＝依規則可以回應的所有活人，不論手上有沒有可用的牌（避免洩漏持有物）。
- **擲骰後窗口**：同時詢問所有可回應的人，收齊後依回合順序加入反應鏈；回應者看不到同一層其他人的選擇（2026-11-25）。
- 不能被取消：勝利判定、死亡判定、已付出的代價、已完成的擲骰或小遊戲結果、次數消耗、系統的上下限修正。

## 5. 名詞定義

| 名詞 | 定義 |
|---|---|
| 取消 | 整個效果不發生 |
| 免疫傷害 | 不承受傷害；卡牌的其他內容照常執行 |
| 免疫負面狀態 | 不會得到新的中毒、凍結、封鎖等狀態；已有的狀態不會移除 |
| 解除負面狀態 | 移除已有的狀態；之後仍可能再得到 |
| 減傷 | 傷害成立但數值降低，最低到 0，不會變成回血 |
| 替代 | 新結果取代原結果 |
| 轉移 | 改變承受者；原目標不再承受被轉移的部分 |
| 防止致命 | 傷害結算後阻止生命歸零，通常留 1 血，消耗 1 次 |
| 回血 | 增加生命值，不超過職業開局生命值 |
| 復活 | 死亡後重新成為活人；不是回血，「不能回血」擋不住復活 |
| 清醒反噬 | 清醒值歸零後，每 3% 改扣 2 血；不是攻擊傷害，不能被減傷、免疫、D6 取代 |

## 6. 傷害結算

| 步驟 | 內容 |
|---|---|
| 1 | 確認來源與原始目標 |
| 2 | 處理代替防守、轉移、替身，決定承受者 |
| 3 | 套用傷害骰的替代（例如命定天罰的 D6） |
| 4 | 基礎傷害 ×（1＋百分比加成合計）；「×3」等特殊倍率只作用於基礎傷害 |
| 5 | 加上固定加成 |
| 6 | 減去減傷、護盾 |
| 7 | 套用**單次最終傷害上限 30** |
| 8 | 檢查傷害免疫 |
| 9 | 扣除生命值 |
| 10 | 檢查致命保護 |
| 11 | 檢查死亡 |
| 12 | 觸發「受到傷害後」「造成傷害後」的效果 |

```
最終傷害 = min( 30, max( 0, 替代後基礎傷害 × (1 + 百分比加成合計) + 固定加成 − 減傷 ) )
```

- 百分比加成一律相加，不連乘。
- 持續傷害（中毒）與清醒反噬不吃攻擊加成，也不受單次上限 30 以外的攻擊規則影響。
- 範例：永恆之槍持有者被破城槌命中 → 基礎傷害改擲 D6 → ×3 → 最多 18，受上限 30 限制。

---

## 7. 死亡與致命保護

1. 生命降到 0 以下時，先檢查一次性致命保護（不老聖杯、死神逆、鳳凰羽毛等）。
2. 同時有多個時，由受傷的玩家選擇用哪一個，一次死亡只消耗一個。
3. 沒有保護就死亡：先觸發持有的復活保留道具（遺囑、靈魂匣、傳承印記、引魂燈；同種只生效 1 個），再資產清空、聖物回到拍賣行、祭壇技能等級歸零、進入死神追逐。
4. 檢查立即復活的效果（審判正、鳳凰羽毛）。
5. 完成死亡與復活後，回到事件流程；勝利等整個事件結算完才判定。

**同時死亡**：同一效果讓多人歸零時，先對所有人完成傷害，再依回合順序處理致命保護，最後一起確認死亡名單。判定大逃殺勝利（其他人同時死亡）時，要等所有死亡與復活效果處理完。

---

## 8. 死亡玩家

- 死亡玩家只能被寫明「死亡玩家」「冥界」「魂火」「復活」的效果選中。
- **死亡玩家通則優先於卡面**：死亡玩家獲勝時只得魂火，不對活人造成傷害、不奪取金幣（例如艾瓦茲）。
- 死亡玩家不能持有聖物。
- 死亡玩家只能使用死亡玩家專用道具；復活時沒用完的全部消失（冥河金幣先兌換）。
- 冥界商店用魂火購買時直接扣除，購買後的魂火不能低於 0。
- 復活後，從下一次合法行動重新加入。
- **復活狀態**：回到起點（不算經過起點）；生命值＝開局生命值的一半＋超出門檻的魂火 × 5（不超過開局生命值）；清醒值 100%；金幣＝職業開局金幣；發 1 顆隨機常見魔術骰子，剩下的冥火骰消失；小技能與大招全部立即可用；祭壇技能等級為 Lv0。
- **復活門檻**：7 個魂火起算，每過 1 周（全場）+1。
- **沒有永久出局**：繞完自己一周還沒集滿時，魂火減半（無條件進位），繼續下一圈追逐。
- **大逃殺判定**：只有在其他所有玩家「同時」是死亡玩家時，唯一的活人才獲勝；有人復活就繼續。時間上限到時，改判生命值最高者（死亡玩家視為 0）；同分比綜合資產，仍同分則並列獲勝。
- **固定回合制**：到達周數時，生命值最高者獲勝；同分比綜合資產，仍同分則並列獲勝。
- **同時死亡**：最後幾位活人在同一效果中同時死亡時，死亡前那一刻生命值最高者獲勝；同分比綜合資產，仍同分則並列獲勝。

## 9. 安全區

位於安全區的玩家，**免疫其他玩家造成的**傷害、負面狀態、掠奪（金錢、手牌）、強制位移、被指定進入試煉。

不能阻止：固定回合結束、已有狀態的倒數、自己支付的生命／金幣／清醒值、全場規則改變、聖物與勝利判定、死後的死神追逐。

## 10. 持續效果

- 「N 回合」＝從成立時算起，到所有人各行動 N 次為止。
- 被暫停算完成一次行動；額外移動不算；作用對象死亡時，普通持續效果移除（寫明「死亡後仍持續」的除外）。

| 種類 | 疊加 |
|---|---|
| 固定傷害加成、百分比加成、回血加成、減傷 | 相加 |
| 中毒 | 最多 2 層 |
| 暫停、凍結 | 不疊加次數，保留較長的 |
| 禁止技能、免疫 | 不疊加，保留較長的 |
| 致命保護 | 可以同時持有，一次死亡只消耗一個 |
| 倍率 | 不連乘，取最高 |

---

## 11. 資源與百分比

| 資源 | 下限 | 上限 |
|---|---|---|
| 生命值 | 0 | 職業開局生命值 |
| 金幣 | 0 | 無 |
| 清醒值 | 0% | 100% |
| 魂火 | 0 | 達到當下的復活門檻（7＋已過周數）時立刻復活 |
| 聖物 | 0 | 每人 1 件 |

- 百分比一律無條件捨去到整數，最低 0。
- 百分比掠奪以結算當下的資源計算，上限依卡面。
- 目標資源不足時，只拿到實際持有量，不會產生負債。
- 「失去金幣」不等於「支付金幣」；付不出代價時，效果不發動。

---

## 12. 領先者與最後一名

```
綜合資產 = 生命值 × 3 + 金幣
```

- 同分依序比較：聖物持有 → 金幣 → 生命值 → 清醒值；仍同分則並列。
- 「指定領先者」：由當前玩家從並列者中選一人。
- 「給最後一名補助」：並列者都拿到，每人得原值 ÷ 並列人數（無條件捨去）。
- 卡面只寫「金幣最多／最少」「生命值最高」「清醒值最低」時，只比那一項。

---

## 13. 文件衝突時的裁定順序

1. 最新的勘誤
2. 本文件《規則優先序》
3. 卡牌或角色的專屬條目
4. 《設定總表》
5. 卡片上的簡短文字
6. UI 提示文字

卡牌專屬條目只能覆寫它明確提到的部分。

## 14. 常見裁定範例

| 情境 | 裁定 |
|---|---|
| 安全區玩家遇到龍息之角 | 來源是其他玩家，安全區免疫 |
| 清醒值歸零後又喝酒 | 清醒反噬，扣 2 血，不能被減傷或免疫 |
| 荒蕪期間用鳳凰羽毛 | 可以復活；復活不是回血 |
| 不老聖杯與死神逆同時存在 | 由受傷的玩家選擇消耗其中一個 |
| 永恆之槍持有者被破城槌命中 | D6 × 3，受上限 30 限制 |
| 兩人想取消同一張牌 | 依回合順序加入反應鏈，最多 2 層 |
| 被暫停的玩家身上有中毒 | 行動開始時先受毒，再執行暫停；暫停照樣推進狀態 |
| 已付 20 金幣的效果被取消 | 不退錢，除非取消效果寫明退款 |
| 雙子座期間抽小牌，盲選 2 張後只採用 1 張 | 沒採用的放回牌庫最底部；剩餘張數只扣 1 |
| 地圖殘頁偷看到壞牌並移到最底部 | 空位由下一張補上；盲選時攤開的仍是最上面 4 張 |
| 祭司命運之輪翻出的大牌 | 發動完洗回大牌牌庫的隨機位置，不進棄牌堆 |
| 傷害已結算後才想用減傷道具 | 不合法；減傷要在傷害鎖定前的反應窗使用 |
| 同一效果先傷害再偷錢，目標因此死亡 | 先完成傷害與死亡；偷錢時對方資產已清空，拿到 0 |
| 被轉移的傷害遇到免疫的新目標 | 新目標免疫，原目標也不承受，傷害歸零 |
