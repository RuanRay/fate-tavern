## 1. 產品定位

| 項目 | 設定 |
|---|---|
| 遊戲本質 | 以**競技**為核心，類似 TRPG 角色扮演形態的團體派對遊戲 |
| 對局形式 | 線上房間制、嚴格回合制。「非即時」指沒有即時動作操作，玩家依序擲骰、輪流行動 |
| 回合外插手 | 有；只能在合法的反應窗使用，每個事件最多 2 層反應；每層最長 5 秒，全員回應即關閉（見《命運酒館_規則優先序》） |
| 遊玩場景 | 沙發派對／多螢幕非對稱：主螢幕顯示地圖並觀戰，手機負責主要操作 |
| 核心版本 | 酒精版 |
| DLC | 非酒精版：喝酒轉成純粹的遊戲內數值機制，成為硬核策略派對遊戲 |
| 現實喝酒驗證（酒精版） | 玩家自主點擊確認 + 視訊互相監督的派對信任制 |
| 現實喝酒單位（酒精版） | 遊戲中「喝一杯」= 現實 1 shot（10ml） |
| 現實飲酒上限（酒精版） | **不設上限**（2026-11-23 決定） |
| 不喝酒選項（酒精版） | 每位玩家的**個人開關**，**隨時可以切換**。開啟時遊戲數值照扣（清醒值照常下降，所有喝酒相關的規則、星座、技能照常計算），只是現實不用喝，也不需要喝酒確認；主螢幕和其他玩家的手機都**不標示**誰開啟（只有本人的手機設定裡看得到開關）（2026-11-24 確認）。和非酒精版 DLC 的差別：DLC 是把喝酒整個改成策略機制 |
| 新手教學 | 第一局的「**引導模式**」：邊玩邊提示，不另做教學關。每位玩家自己開關，第一次玩**預設開啟**；系統記住每種提示是否看過，第一次遇到某個機制時才出現。提示**只出現在當事人的手機上**，不打斷主螢幕；**規則不簡化**，新手和老手可以同桌正式對戰；提示**只說明規則和選項效果**，不推薦選項（2026-11-24 確認） |
| 玩家人數 | 2～10 人 |
| 目標單局時長 | 4 人局約 **2.5 小時** |
| 每次行動平均時間 | 估算基準 **1 分鐘** |
| 世界觀 | 美術與故事為**西方中世紀**；塔羅牌、星座作為核心系統保留 |
| MVP 形態 | 數位灰盒 |
| 機率呈現（2026-11-25 確認） | 所有機率只在伺服器；卡牌用**有限牌庫＋手機盲選**（第 5 節「牌庫與抽牌」）；擲骰可以**搖手機**，力道只影響主螢幕的骰子動畫，不影響點數；高風險擲骰播放**近失演出**；開局公布**種子承諾**、結算公布種子，任何人都能驗證這局沒被動手腳（見《技術規劃》§12-5）；不使用隱藏的動態權重 |

## 2. 時間單位

| 單位 | 定義 |
|---|---|
| 行動 | 一位玩家自己行動一次 |
| 回合 | 所有玩家都行動一次 |
| 周（全場） | 以所有活人中**最少的繞行圈數**為準，**最少為第 1 周**：周數＝max(1, 最少圈數)。開局到最少圈數達 1 之前都是第 1 周（所以第 1 周約是其他周的兩倍長）。例：有人繞 4、5 圈，有人繞 3 圈，當下是第 3 周（2026-11-24 確認） |
| 自己的一周 | 玩家自己繞完一圈。大招冷卻、追獵次數、商人被動、死神追逐、聖物繞行都用這個單位 |

### 各項時間條件

| 項目 | 條件 |
|---|---|
| 星座切換 | 每 1 周（全場）切換一次；同一個星座最多持續 **X 回合**，時間到強制切換。**X ≈ 地圖格數 ÷ 2.5**（例：40 格 → 16 回合） |
| 星座效果持續 | 到下一次切換為止 |
| 監獄 | 下一次行動被暫停 |
| 事件卡「暫停」類效果 | 下一次行動被暫停 |
| 安全區 | 到自己下一次行動之前，免疫其他玩家造成的傷害、負面狀態、掠奪與強制位移；不免疫全場規則、勝利判定與自己支付的代價 |
| 試煉之地佔位對決 | 到停在上面的人下一次行動之前有效 |
| 死神追逐 | 死亡後立刻回到起點，繞完自己一周前要集滿 7 個魂火 |
| 聖物持有者 | 買到後立刻回到起點，繞行自己一周 |
| 聖物持有期間的配對 | 持有者繞行期間，所有配對對手預設是持有者 |
| 繞過起點的收入 | 每次經過起點時發錢；**剛好停在起點也算經過**，照樣領 30 並計一圈（同一次行動最多領 1 次） |
| 血量勝利（固定回合制） | 依目標時長反推周數：周數 = 目標時長（分鐘）÷（人數 × 1 分鐘 × 一周回合數）。4 人局 28 格約 **4 周**；實作上以圈數判定：**最少圈數達到 4 時結束**（約 37 回合、2.5 小時） |
| 小技能冷卻 | 3 回合 |
| 大招冷卻 | 自己繞一周 1 次（另有規定者除外） |
| 計時的共通規則 | 被暫停也算完成一次行動；額外移動不算行動，不推進冷卻與持續時間；作用對象死亡時，身上的持續效果移除 |

## 3. 地圖

- **規則層與畫面層分離**：
  - 規則層：地圖是一串有順序、首尾相連的格子。所有規則（移動、射手座的「前方」、逆行）都只看順序。
  - 畫面層：程式把格子序列自動排成指定外形；同一份地圖可以換外形顯示。
- **外形**：正多邊形，邊數盡量多；不同人數用不同多邊形。4 人局為**正七邊形**（28 格）。
- **地標格**：依順序定義的特殊位置（取代「角落」的概念）。以正多邊形顯示時落在角上；4 人局正七邊形有 7 個地標格。地標格只用來把重要格子固定在地標位置，本身沒有額外效果；玩家自建地圖時可以自行調整位置。
- **內外圈岔路**：4 人局先不使用。
- **玩家自建地圖**：MVP 只開放「選擇格子種類、排列順序」，外形由程式自動排列；自由形狀與岔路之後再做（可參考六角網格閉合環方法）。
- **主螢幕呈現的優先順序**：格子要大、看得清楚玩家之間的位置關係、有代入感；玩家資訊必須清楚明瞭。
- **鏡頭**：混合模式。平常顯示全景，輪到誰或發生事件時跟隨移動。
- **回合提示**（全部採用）：主螢幕上該玩家的角色發光或聚光燈效果、顯示玩家名字與角色立繪、輪到的玩家手機震動或發出聲音、每個職業有專屬的出場動畫或音效。

### 資訊公開規則

| 公開（主螢幕顯示） | 不公開（只在自己的手機上） |
|---|---|
| 職業 | 道具（使用時短暫揭露） |
| 地圖上的位置 | 手牌數量與內容（道具牌、魔術骰子） |
| 生命值 | 保留下來的塔羅小牌 |
| 清醒值 | 持有的塔羅大牌 |
| 金幣（精確數字） | 聖殿騎士被動選定的 D8 數字 |
| 狀態（中毒、死神追逐與魂火、監獄、安全區、獅王、雙子搭檔、聖物持有者） | 隱藏陣營身分（MVP 之後） |
| 大招是否可用 | 賭場下注內容（開獎前；開獎時公開） |
| 小技能冷卻 | |
| 拍賣出價 | |
| 小遊戲過程與結果 | |
| 各牌庫剩餘張數（不含種類分布） | 牌庫順序、盲選時牌背的內容 |

- 主螢幕的公開資訊用圖示和數值條呈現；詳細說明放在手機上。
- 鏡頭跟隨某位玩家時，可以暫時放大那位玩家的資訊欄。
- **隱藏資訊的揭露**：攻防小遊戲分出勝負後，會播放一段攻擊動畫，動畫中顯示傷害加成的過程，大家會看到用了哪些道具；動畫結束後再次隱藏。聖殿騎士被動的選定數字、持有的塔羅大牌，被觸發或使用時**不揭露**。
- 地圖大小**依玩家人數調整**：人越多地圖越大，但節奏要變快。
- **4 人局（MVP）：28 格**（一周約 9.3 回合，2.5 小時約 4 周，星座強制切換 X ≈ 11 回合）。
- 其他人數的格數 ⚠️ 延後討論。
- 格子比例**隨人數變動**；原本的「酒館 40%、試煉之地 30%、其他 30%」作為參考基準。

### 格子節奏分類（暫定）

| 分類 | 格子 | 說明 |
|---|---|---|
| 大節奏：加速 | 試煉之地、拍賣行、神殿 | 明顯推進血量勝利或經濟勝利，或影響全場 |
| 大節奏：波動 | 賭場 | 金錢大幅重新分配，製造翻盤 |
| 小節奏 | 酒館、商城、煉金工坊、祭壇 | 逐步成長、小事件 |
| 減速格 | 監獄、安全區 | 讓單一玩家停止或免疫 |
| 固定格 | 起點 | 不隨人數調整 |

- **人越多：增加大節奏加速格，減少減速格。**
- 拍賣行、賭場、神殿只要任何人踩到就觸發，觸發次數會隨人數增加；換算成每分鐘則跟 4 人局差不多，但每次觸發的時間會變長。
- 反方向移動（例如雙魚座）：照常觸發格子效果；經過起點時不計圈，也沒有收入。

### MVP 格子（4 人局 28 格：酒館 11、試煉之地 8，其餘各 1）

- **排列方式（2026-11-24 確認）**：每種格子有固定編號，**起點固定在第 0 格**，其餘 27 格每局開局時用對局種子**隨機排列**（可重播）。地標格只是畫面上正七邊形的 7 個頂點，不指定格子種類。**排列限制**：試煉之地最多 2 格相連（不能 3 格以上連續）；其他不限制。

| 格子 | 功能 |
|---|---|
| 起點 | 經過或停在起點時領取 30 金幣 |
| 酒館格 | 抽塔羅小牌（佔大多數格子） |
| 試煉之地 | 抽試煉卡，處理對戰與攻防 |
| 神殿格 | 抽塔羅大牌 |
| 商城格 | 開放購物，MVP 只做普通商城 |
| 煉金工坊格 | 付費把 1 個道具升級成同類別、高一級的道具（取代原本的鐵匠鋪） |
| 祭壇格 | 停留：升級技能、切換星象、聖殿騎士改數字；經過：小祈福（詳見下方「祭壇格」） |
| 監獄格 | 暫停一次行動 |
| 安全區 | 到自己下一次行動之前，免疫其他玩家造成的傷害、負面狀態、掠奪與強制位移（範圍同第 2 節） |
| 拍賣行 | 固定格子，踩到時開放一次拍賣（見第 9 節） |
| 賭場格 | 全部玩家共同參與的全域賭博（見第 9 節） |

**之後可能加入的格子**：黑市、當鋪、傳送陣、皇宮、法庭等，會陸續增加。

### 祭壇格（2026-11-24 確認）

| 項目 | 規則 |
|---|---|
| 觸發 | **停留**：可以使用全部功能，三項（升級技能、切換星象、聖殿騎士改數字）可以在同一次停留中都做。**經過**：只能做 1 次小祈福 |
| 升級技能 | 每次停留最多升級 **1 次**；每個技能最多升到 **2 級**；升到 Lv1 費用 **60**、升到 Lv2 費用 **120**（以金幣價值計）。各技能的升級效果見第 11 節「技能升級（祭壇）」 |
| 支付方式 | 金幣、生命（1 血抵 3 金幣）、喝酒（1 杯抵 6 金幣）、道具（依商城售價或底價的 **100%** 折算），可以混合支付；多付不找零；聖物不能拿來支付；用生命支付不能讓生命值降到 0 以下（最少留 1） |
| 切換星象 | 付 **50 金幣並喝 3 杯**（約 68 金幣價值），從這一輪還沒出現過的星座中指定 1 個；切換後重新計算「同一星座最多持續 X 回合」；每周固定切換的時間點不變 |
| 聖殿騎士改數字 | 付 **20 金幣**，重新選定被動的 D8 數字（只有停留時可以改） |
| 小祈福（經過） | 二選一：**A.** 付 10 金幣，從「回 3 血」「清醒值 +5%」「下一次攻防傷害 +2」中選一個；**B.** 免費擲 D8：1～2 沒有獎勵、3～4 得 5 金幣、5～6 回 3 血、7 清醒值 +5%、8 得 15 金幣（期望值約 6.6 金幣） |
| 死亡 | 死亡時技能等級**全部歸零**，不保留；死亡玩家不能使用祭壇（經過時也不能小祈福） |

- 每位玩家整局平均約停在祭壇 1 次，通常在中盤，升級後大約還有 2 圈可以使用；Lv1 的目標是每圈約 25～30 金幣價值。

## 4. 數值系統

**基礎骰子**：D8

| 數值 | 設定 |
|---|---|
| 生命值 | 以 100 為中心，依職業上下調整；歸零即死亡 |
| 經濟值（金幣） | 以 20 金幣為開局基礎。非經濟型職業開局一律 20；經濟型職業依角色調整 |
| 清醒值 | 所有人開局 100%（完全清醒），上限 100% |

### 基礎數值

| 項目 | 數值 |
|---|---|
| 起點收入 | 每次經過 **30 金幣**；某些經濟型職業或道具可以調整。繞圈快的人收入較多，是可以接受的 |
| 基礎傷害 | 以 **10** 為基準上下調整（大約被打 10 次會死） |
| 喝一杯 | 清醒值 **−3%** |
| 賭場最低下注 | **10 金幣** |
| 聖物底價 | **300 / 400 / 500 金幣**（3 件各不相同） |

### 數值匯率（4 人局；單位＝1 金幣）

> 推導依據：每局每人大約經手 300 金幣、承受 100～130 傷害、行動約 37 次；以「300 金幣的聖物 ≈ 打倒 3 位對手的 300 傷害」做為勝利路線的對稱點。所有道具、技能、卡牌的數值都以這張表校正。

| 項目 | 約值（金幣） | 說明 |
|---|---|---|
| 自己 1 點生命值 | **3** | 回 1 血 ≈ 3 金幣；扣 1 血 ≈ −3 金幣 |
| 對一位對手造成 1 點傷害 | **1** | 約等於自己的血值 ÷ 對手人數；針對領先者時約 1.5 |
| 1% 清醒值 | **2** | |
| 喝 1 杯（−3%） | **6** | |
| 自己 1 點生命值（生命值 30 以下時） | **4.5** | 低血區間，接近死亡，價值較高 |
| 1 次行動 | **20** | 暫停一次 ≈ −20 金幣（含移動、停留格事件、圈數進度）；只失去移動、仍觸發當前格時算 10 |
| 隨機移動 1 格 | **2** | 已包含「靠近起點收入」的攤提，計算時不要再另外加起點收入 |
| 自選移動 1 格 | **3** | 精準指定到重要格（神殿、拍賣行、試煉之地、起點）另加 10～20 |
| 繞 1 圈 | **60** | 起點收入 30 + 途中事件約 30 |
| 1 張手牌（平均） | **20** | |

- 卡牌校正目標：好事件約 +20～30、壞事件約 −20～30、取捨事件期望值約 0 ±10。
- 人數改變時，「對對手的傷害」匯率要跟著重算（對手越多，單點傷害越不值錢）⚠️ 其他人數之後再算。
- **全體效果用總預算**：影響「其他所有玩家」的效果，以 4 人局的總量為預算，依人數平分（例如龍息之角總傷害 90，4 人局每人 30、7 人局每人 15）。
- **綜合資產**＝生命值 × 3＋金幣。所有「領先者」「最後一名」「排名」都用綜合資產判定；卡牌只寫「金幣最多／最少」「生命值最高」時，只看那一項。

### 加成計算規則

- 百分比加成換算成倍率，例如 +20% = ×1.2。
- 多個加成同時存在時**相加**。例：+50% 和 +100% 同時生效，合計 +150%，也就是 ×2.5。
- MVP **不設加成上限**；傷害另有單次最終傷害上限 30（《規則優先序》§6）。上限是否需要，依模擬與灰盒結果再議（第 13 節「MVP 之後」）。

### 醉意階段（底層規則）

| 階段 | 範圍 | 約幾杯 | 正面效果 | 負面效果 |
|---|---|---|---|---|
| 清醒 | 100～71% | 開局喝 10 杯後離開 | **+20%** | **−20%** |
| 微醺 | 70～51% | 約 7 杯 | 不變 | 不變 |
| 爛醉 | 50～0% | 約 17 杯 | **−20%** | **+20%** |

- 正面效果：得到金幣、回血、回復清醒值、自己的傷害加成；負面效果：失去金幣、扣血。
- **喝酒杯數不算負面效果**，不受階段影響。
- 全域傾向是「清醒好、爛醉差」；「兩端各有好壞」由卡牌的階段特殊效果提供（例如爛醉時才有的爆發報酬）。
- 卡牌寫明的階段效果優先，數字為最終值，不再疊加全域 ±20%；卡牌沒寫的，才套用全域規則。
- 清醒值**不影響**小遊戲。
- 塔羅小牌非 MVP 的 36 張：**逆位**在爛醉時不再疊加全域「負面 +20%」，避免和「爛醉逆位 70%」雙重懲罰。
- 幅度 ±20% 為暫定，之後可再調整。

### 清醒值規則

- 大部分情況下會趨向中間值。
- **過高**：某些需要較低清醒值才能觸發的狀態，會無法觸發。
- **過低**：一般會有負面效果，但在特定機制下會帶來強大的正面效果，給玩家冒險換報酬的選擇。
- 在許多效果中，清醒值的高低會決定攻擊效果，以及經濟效果的加成。
- **歸零之後**，後續的清醒值扣除改扣血量：**每 3%（＝喝 1 杯）扣 2 血**，不足 3% 的部分照比例捨去。這叫「清醒反噬」，不算攻擊傷害，不能被減傷、免疫、命定天罰的 D6 取代。沒有獨立的「醉死」。
- **生命值上限**＝職業開局生命值；回血不能超過上限。
- **百分比計算**：一律無條件捨去到整數，最低 0；被掠奪的人資源不足時，只拿走他實際持有的量，不會負債。
- 增減來源是角色機制、道具、遊戲過程，**主要透過塔羅小牌的事件**；小牌事件多少都會帶到喝酒互動。
- 喝酒來源：
  - 事件卡強制。
  - 自己主動選擇喝，但需要道具或角色技能作為前提。
  - 攻防失敗的懲罰。
  - 星座效果。
- **技能消耗清醒值**（例如戒律、識途）：酒精版裡也只是遊戲數值直接扣除，不需要現實喝酒。

### 經濟來源

- 起點收入、事件卡、特定格子、交易、職業技能、道具、賭場、星座效果、各種事件與活動。

## 6. 星座系統

### 基本規則

- 正式版是**黃道十二星座**，MVP 使用 4 個。
- 每 1 周（全場）切換一次；也可以透過特殊效果卡，或停在祭壇付 50 金幣並喝 3 杯，從這一輪還沒出現過的星座中指定（見第 3 節「祭壇格」）。

## 7. 玩家互動與戰鬥

### 陣營與互動

- 陣營形態：個人混戰、臨時結盟、隱藏陣營，以及團隊合作／團隊對抗 ⚠️ 細節未定。
- 互動類型：攻擊、防禦、交易、合作、團體競技。

### 攻防觸發

- 大部分情況下，**玩家不能主動選擇攻擊目標**。
- 試煉卡的對手：由卡片寫明條件決定（例如「清醒值最低的人」），或隨機。
- 小牌事件、大牌、星座也會觸發攻防。
- 例外：特定卡牌效果、全局效果、角色技能可以指定對象。
- **佔位對決**：某位玩家停在試煉之地，到他下一次行動之前，有其他人也停在試煉之地時，後到的人照樣抽試煉卡，但對手固定是停在上面的人。只有「停留」才算，經過不算。超過兩人時，改成團體競技（例如一對一對一）。
- **配對優先順序**：技能 > 佔位對決 > 死亡玩家優先配對。
- **避戰**：只能透過道具、特殊卡片或技能，**不限次數**；攻擊方不能放棄攻擊；死亡玩家發起的對決，活人不能避戰。

### 試煉卡（主題 E）

- 以**盧恩字母**（古弗薩克）為靈感，依傳統字義設計。MVP 12 張，正式版 24 張。
- 攻守角色由卡片決定：抽牌者可能是攻擊方或防守方。
- 卡片之間的差異：對手條件、指定小遊戲種類、傷害大小、額外賭注、特殊規則（旁觀者下注、二對一等）。
- 每張都有清醒、微醺、爛醉三種結果。
- **MVP 12 張**：費胡、瑟里薩茲、安蘇茲、給勃、哈格拉茲、瑙提茲、艾瓦茲、佩斯洛、依瓦茲、貝卡諾、瑪納茲、達加茲（內容見《命運酒館_試煉卡24張》）。

### 攻防小遊戲

- 約 **15 秒**的真正小遊戲（約 3 秒準備＋10 秒對決），在手機上操作，其他人看主螢幕觀戰。
- 小遊戲的勝負**直接決定**攻擊成功或失敗。
- 大部分情況只有攻擊方和防守方參加。
- 旁觀者可以參加的前提：特殊道具、特殊卡牌、角色技能、團隊活動或團隊攻略，或小遊戲本身有團體娛樂性（例如比大小時，旁觀者下注誰比較大或下注數字）。

### 傷害結算

- 基礎傷害以 10 為基準，由觸發的卡牌或事件決定。
- 道具、職業技能可以加成數值。
- 防守方贏了基本上不受傷；持有特殊道具時，可以反擊或得到獎勵。
- **基本懲罰（卡面沒寫結果時，2026-11-24 確認）**：防守方落敗受 **10** 傷害；攻擊方落敗**沒有懲罰**。適用於小牌、大牌、星座等只寫「發動攻防」而沒寫勝負結果的情況。
- **傷害公式**：最終傷害 ＝ min（30，max（0，替代後的基礎傷害 ×（1＋百分比加成合計）＋固定加成 − 減傷））。
  - 「替代」例如命定天罰的 D6；「×3」等特殊倍率只作用於基礎傷害。
  - 百分比加成一律相加，不連乘。
  - **單次最終傷害上限 30**；持續傷害（中毒）與清醒反噬不受攻擊加成影響。
- 完整的結算順序見《命運酒館_規則優先序》。

### 監獄入口

- 踩到監獄格、卡面寫明入獄的事件卡或試煉卡、其他特殊效果。
- **攻防落敗本身不入獄**；只有卡面寫明時才入獄（2026-11-24 確認）。

## 8. 死亡：死神追逐（冥界巡禮＋惡靈作祟）

- **懲罰程度**：中度。努力的話大約一半機率能復活。
- 生命值歸零就死亡，資產全部清空，回到基礎遊戲池（銀行或牌庫）。
- 死亡後**立刻回到起點**，進入「死神追逐」狀態。
- 必須在**繞完自己一周之前**集滿魂火才能復活。所需魂火從 **7 個**起算，**每過 1 周（全場）+1**（第 1 周 7、第 2 周 8、第 3 周 9…），以「當下的周數」判定。
- **沒有永久出局**：繞完一周還沒集滿時，魂火**減半（無條件進位）**，繼續下一圈追逐（例：5 → 3、3 → 2、1 → 1）。追逐期間照常作祟、抽冥界事件、挑戰試煉之地。
  - 懲罰：每多追一圈約 9.3 回合，這段時間退出經濟競速。
  - 全場零淘汰，死亡玩家全程都有事做（設計紅線 4）。

### 魂火來源

| 來源 | 魂火 |
|---|---|
| 停在試煉之地，戰勝活人 | **+2** |
| 停在試煉之地，戰勝其他死亡玩家 | **+3**；輸的死亡玩家 −1 |
| 活人在試煉之地被配對到你（你不在試煉之地上），你獲勝 | **+1** |
| 停在酒館：抽「冥界事件」（12 張，v4 直接期望約 +0.39，見《命運酒館_塔羅小牌56張》第 8 節） | 依卡片 |
| 停在神殿：向神祈禱 | **+2** |
| **惡靈作祟**：活人移動時經過或停在你所在的格子 | **+1**，對方被作祟喝 1 杯 |

- 試煉之地隨機配對時，死亡玩家的優先值會提高。
- 死亡玩家發起的對決，活人**不能避戰**。

### 模擬結果（v24 規則，4 人局、28 格、1 位死亡玩家對 3 位活人、每種情況 2 萬次）

> 規則：冥界事件 12 張、死亡時得 1 顆冥火骰、復活門檻 7＋已過周數、未滿則魂火減半（進位）繼續追、對局約 37 回合結束。

| 死亡時間點 | 對決勝率 | 第一圈內復活 | 對局結束前復活 |
|---|---|---|---|
| 第 1 周初 | 30% | 37% | 98% |
| 第 1 周初 | **50%** | **52%** | **100%** |
| 第 1 周初 | 70% | 67% | 100% |
| 第 2 周初 | 50% | 42% | 99% |
| 第 2 周末 | 50% | 32% | 92% |
| 第 3 周末 | 30% | 13% | 35% |
| 第 3 周末 | **50%** | **23%** | **56%** |
| 第 3 周末 | 70% | 36% | 75% |

- 前期死亡：第一圈約一半復活，追到第二圈幾乎都會回來，懲罰是「退出約 1～2 圈的經濟競速」。
- 後期死亡：門檻變高、剩下的時間變少，復活率明顯下降，局面會自然收斂。
- 小遊戲打得越好，復活率越高，符合「努力就有機會」。
- 前期死亡的人幾乎都會回來，所以大逃殺通常要靠時間上限結束，這是預期中的結果。
- 活人越多，作祟機會越多，復活率會上升（例如 5 位活人約 78%）。其他人數的魂火需求，之後依人數重新校正 ⚠️。

### 死亡期間的其他規則（已確認）

- 輸給活人時，**不失去魂火**。
- 活人輸給死亡玩家時，除了讓對方拿到魂火，自己不會扣血或扣錢；**這條通則優先於卡面**（例如艾瓦茲寫的傷害，死亡玩家獲勝時不會造成）。
- 清醒值與喝酒**暫停**：死亡期間不受喝酒影響；復活時清醒值回到 100%。
- 商城、煉金工坊、拍賣行、賭場**不能使用**；監獄、安全區**照常生效**。
- 只能使用死亡玩家專用的道具。

## 9. 商城、拍賣行與賭場

### 商城

- 商城分三種：普通商城、特殊商城、玩家商城。
- 販售內容為道具（不做裝備）。
- 玩家商城包含兩種概念：玩家之間上架交易（拍賣行／擺攤），以及依職業客製化刷新的個人專屬商店。
- 商城的開啟條件：看情況 ⚠️。
- **MVP 只做普通商城**（踩到商城格開放購物）。
- **冥界商店**：死亡玩家停在商城格時，改開冥界商店（見第 8 節「死亡玩家專用道具」）。
- **普通商城商品（2026-11-24 確認）**：每位玩家停留時重新隨機抽 **4 件**道具：普通 3 件＋優良 1 件（不重複）；另外固定販賣 **1 顆隨機常見魔術骰子**（10 金幣）。價格照道具表。

### 拍賣行

- 地圖上固定的格子，有玩家踩到時開放一次拍賣。
- 平常拍賣較高等級的特殊道具，拍賣品會隨機切換。
- 全部玩家共同參與競標，設有底價；經濟值超過底價的玩家才能參加競標。
- **競標形式（2026-11-24 確認）**：**公開加價**。有人出價時倒數重置為 **8 秒**，整件最長 **30 秒**；最小加價幅度為**底價的 5%（最少 5 金幣）**；時間到由最高出價者得標。
- **每次拍賣 3 件（2026-11-24 確認）**：一般拍賣品 2 件（史詩或傳說道具）＋**壓軸 1 件**（聖物或傳說道具）；依序拍賣，壓軸最後。聖物保證出場時，壓軸固定是聖物。
- 玩家付出的拍賣金歸系統所有。
- 3 件**聖物**混在隨機拍賣品裡，不一定會出現。
  - 底價：300 / 400 / 500 金幣，各不相同。
  - 每件聖物有不同的效果（見下表）；價格不同，效果強度也不同，但每件都要有足以撐過繞行的強度。
  - **聖物效果**（只在持有者繞行期間生效）：

| 聖物 | 底價 | 效果 |
|---|---|---|
| 賢者之石 | 300 | **煉成之陣**：買下時，手上最多 3 個道具各升一級；繞行期間每次停在格子上，額外得到 1 個隨機普通道具（最多 5 個） |
| 不老聖杯 | 400 | **不死誓約**：受到致命傷害時，改成留 1 血；第一次觸發另外立刻回 30 血，第二次只留 1 血、不回血；整段繞行最多觸發 2 次 |
| 永恆之槍 | 500 | **命定天罰**：①**戰勝時**（包含防守成功）：除了這場攻防原本的傷害之外，持有者另外擲 3 顆 **D12**，依序決定吸取對手的生命值、清醒值（%）、金幣，並轉移給自己。②**戰敗或受到任何傷害時**（包含攻防以外的傷害，例如投石索、龍息之角、高塔、射手座）：基礎傷害一律改成 **D6**，由攻擊方擲骰；道具、星座、卡牌的加成照常計算（例如磨刀石 D6 + 15、破城槌 D6 × 3；最終仍受單次上限 30） |

  - 命定天罰的 3 顆 D12 和戰敗時的 D6 都可以使用魔術骰子（規則見「魔術骰子」的非 D8 骰規則）。
  - 對手清醒值不夠吸時，照清醒值規則改扣血量；持有者清醒值已滿時，超過 100% 的部分改成回血，每 2% 回 1 血。
  - 強度估算（繞行約 8 場攻防、勝率 50%）：D12 平均 6.5，持有者約回 26 血、只受約 14 傷害，約等於抵掉 60 傷害，另外吸走全場清醒值與金幣；其他玩家仍然可以靠疊加道具加成打死持有者。
  - 2026-11-23 依檢核修正：賢者之石「全部升到最高級」可套利 → 改成最多 3 個各升一級；不老聖杯第二次免死不回血；永恆之槍 D20 → D12。
  - **持有者在繞行途中死亡**：聖物回到拍賣行，重新混入拍賣品。（「掉在死亡格子上讓別人搶」「交給擊殺者」之後可以透過其他機制實現。）
- **保證出場**：
  - 3 人以上（含 3 人）達到聖物底價時，之後每次拍賣，聖物都會作為壓軸出場。
  - 部分道具或效果卡可以保證「這一次拍賣」聖物作為壓軸出場。

### 賭場

- MVP 就加入。全部玩家共同參與。
- 最低下注 **10 金幣**；**每局上限＝持有金幣的 30%（無條件捨去，但最少可以押 10）**；持有不到 10 金幣不能下注（2026-11-24 確認）。
- **流程**：有人停在賭場時，由**停的人選 1 種遊戲**，全場玩 **1 局**。
- 系統擲的骰子、輪盤、發牌都不能用魔術骰子。
- 賭博小遊戲（MVP 全部收錄）：

| # | 遊戲 | 玩法 | 形式 |
|---|---|---|---|
| 1 | 猜大小 | 系統擲 3 顆骰，押總點數大或小 | 玩家對莊家 |
| 2 | 猜單雙 | 系統擲骰，押奇數或偶數 | 玩家對莊家 |
| 3 | 紅黑輪盤 | 押紅、黑或單一數字（數字賠率高） | 玩家對莊家 |
| 4 | 比大小（抽牌） | 每人抽一張，最大者贏走彩池 | 玩家互相競爭 |
| 5 | 簡化 21 點 | 最接近 21 點且不爆者贏 | 玩家互相競爭 |
| 6 | 高低連猜 | 猜下一張牌比較高或低，可以停手領獎或繼續賭 | 個人挑戰 |
| 7 | 吹牛骰 | 蓋骰喊數，可以抓別人說謊 | 玩家互相競爭 |

- **賠率（2026-11-24 確認，照真實賭場標準）**：

| # | 遊戲 | 形式 | 規則與賠率 |
|---|---|---|---|
| 1 | 猜大小 | 玩家對莊家 | 3 顆 D6 總和 4～10 小、11～17 大；1:1；豹子（三顆相同）莊家通吃（莊家優勢約 2.8%） |
| 2 | 猜單雙 | 玩家對莊家 | 3 顆 D6 總和單或雙；1:1；豹子莊家通吃（約 2.8%） |
| 3 | 紅黑輪盤 | 玩家對莊家 | 37 格（1～36 紅黑各半＋綠 0）；紅／黑 1:1、單一數字 35:1；開 0 押紅黑全輸（約 2.7%） |
| 4 | 比大小（抽牌） | 玩家互相競爭 | 每人下注進彩池；各抽 1 張，最大者全拿，平手平分；系統不抽成 |
| 5 | 簡化 21 點 | 玩家互相競爭 | 每人下注進彩池；最接近 21 且不爆者全拿，平手平分；系統不抽成 |
| 6 | 高低連猜 | 個人挑戰（對莊家） | 猜下一張比較高或低；連中 1 張 ×1.5、2 張 ×2、3 張 ×3、4 張 ×5、5 張 ×8（上限）；猜錯全輸、平手算輸、可隨時停手領獎 ⚠️ 期望值待模擬確認 |

  - **賭徒當莊家**時：賭徒取代系統，自負盈虧；玩家輸的錢歸賭徒，玩家贏的錢由賭徒支付。

## 10. 勝利條件

| 路線 | 條件 |
|---|---|
| 經濟勝利 | 在拍賣行競標到聖物（賢者之石、不老聖杯、永恆之槍，3 件皆唯一，底價 300 / 400 / 500 金幣）；買到後立刻回到起點並繞行自己一周，期間所有配對對手預設是持有者 |
| 血量勝利：大逃殺制 | 場上其他所有玩家**同時**處於死亡（死神追逐）狀態時，唯一的活人獲勝。**時間上限**：與固定回合制相同的周數（4 人局約 4 周），時間到就改判「生命值最高者獲勝」（死亡玩家視為 0）；同分比綜合資產，仍同分則並列獲勝 |
| 同時死亡 | 最後幾位活人在同一個效果中同時死亡時，**死亡前那一刻生命值最高者獲勝**；同分再比綜合資產；仍同分則並列獲勝 |
| 血量勝利：固定回合制 | 依目標時長反推周數（4 人局約 4 周）；結束時血量最高者獲勝；同分比綜合資產，仍同分則並列獲勝 |

兩種血量勝利依模式或局型切換，都保留。

- **血量判定同分**（固定回合制結束、大逃殺時間上限到時）：生命值最高的活人有兩位以上同分時，比綜合資產（與「同時死亡」相同）；仍同分則並列獲勝（與《規則優先序》§12「仍同分則並列」一致）。
