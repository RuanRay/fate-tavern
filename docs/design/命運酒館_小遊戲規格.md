## 1. 共通規則

### 1-1 時間軸（每場 ≤ 15 秒，不含載入）

| 階段 | 時間 | 內容 |
|---|---|---|
| 載入 | 不計 | `minigame.prepare`：手機載入資源、做時鐘校正（5 次）→ `minigame.ready` |
| 開始 | — | `minigame.start { startAt, seed }`：`startAt` 至少比送出時間晚 1.5 秒；題目種子這時才送 |
| 倒數 | 3 秒 | 手機與主螢幕同步顯示 3、2、1（部分遊戲在倒數期間顯示目標，例如符文辨識的目標符文） |
| 對決 | 各遊戲 ≤ 10～12 秒 | 見各遊戲；可以提前結束 |
| 上傳 | ≤ 1 秒 | 手機送 `minigame.submit`（分數＋`inputLog`） |
| 結算 | — | 伺服器重算、套用係數、判定勝負 → `minigame.resolved` |

### 1-2 支援的對戰形式（MVP）

| 遊戲 | 1v1 | 1v1v1 | 2v1 |
|---|---|---|---|
| 拔河 | ✓ | — | ✓ |
| 拔劍決鬥 | ✓ | ✓ | — |
| 符文辨識 | ✓ | — | — |
| 點酒單 | ✓ | — | — |
| 鍛鐵 | ✓ | — | — |
| 停錶 | ✓ | — | — |
| 符文猜拳 | ✓ | — | ✓ |
| 膽小鬼 | ✓ | — | — |
| 數金幣 | ✓ | ✓ | — |

### 1-3 計分由伺服器重算

- 手機回報的分數只當參考；伺服器用「種子＋`inputLog` 的時間點」**自己重算**一次，以重算結果為準；兩者不一致時記入遙測（可能是程式錯誤或竄改）。
- `inputLog` 的時間一律換算成「相對 `startAt` 的毫秒」（用時鐘校正的時差）。
- 拔河例外：伺服器每 100 毫秒直接累計點擊數。

### 1-4 係數與加成

| 項目 | 規則 |
|---|---|
| 2v1 | 單人一方：拔河每次點擊力量 ×1.5；符文猜拳得分 ×1.5（係數 `two_v_one_factor`，設定檔可逐款調整） |
| 戰吼號角 | 依各遊戲（見設定總表 §7）；**畫面類**（點酒單多看一次、鍛鐵甜蜜點加寬）以 `myModifiers` 只送本人；**計分類**由伺服器結算時套用 |
| 清醒值 | 不影響任何小遊戲（設定總表 §4） |

### 1-5 平手

依序判定（2026-11-25 確認）：
1. 各遊戲自己的平手判定（見各節）。
2. 仍平手：**加賽一回合**（各遊戲的加賽內容見各節「加賽」，每次 ≤ 5 秒；有沒有攻守之分都一樣）。戰吼加成在加賽照樣有效。
3. 加賽仍平手：用 `minigame` 流擲一次決定。
- 加賽會讓該場超過 15 秒（最多約 20 秒）；遙測記錄加賽次數，灰盒時觀察頻率。

### 1-6 斷線

| 情況 | 處理 |
|---|---|
| 開始前斷線（`ready` 前）或 `ready` 逾時 | 系統依 40% 判定該玩家獲勝（與代打中相同；1v1v1 同下列），避免「斷線越久越有利」 |
| 進行中斷線 | 以斷線前已送出的輸入計分 |
| 已在代打中（斷線超過 60 秒） | 系統依 40% 判定該玩家獲勝（1v1v1：對每位真人各擲一次，勝場多者排前） |

### 1-7 反作弊（⚠️ 門檻灰盒校正）

| 檢查 | 門檻 | 處理 |
|---|---|---|
| 點擊頻率 | 每人每秒最多 15 次 | 超出的點擊不計 |
| 反應時間 | < 100 毫秒 | 標記可疑，該次以 300 毫秒計 |
| `inputLog` 筆數 | > 2000 筆 | 截斷並標記可疑 |
| 分數與重算不一致 | — | 以重算為準並記錄 |

- 可疑紀錄只寫入遙測，不自動處罰；灰盒測試後再決定。

### 1-8 主螢幕與手機的共通呈現

- 主螢幕：上方顯示小遊戲名稱與雙方（或三方）頭像；結束時大字顯示勝方與分數，約 2 秒。
- 手機：全螢幕直式、保持螢幕常亮；只用形狀與圖示區分，不只靠顏色（色盲友善）。

## 2. 拔河（手速）

| 項目 | 規格 |
|---|---|
| 時間 | 對決 10 秒，可以提前結束 |
| 玩法 | 狂點螢幕，把繩子拉向自己這一側 |
| 繩子 | 位置從 0 開始，兩側勝利線 ±100；每 100 毫秒更新：位置 +＝（A 側力量總和 − B 側力量總和） |
| 力量 | 每次點擊 1；戰吼 ×1.25；2v1 的單人一方 ×1.5；團隊＝成員加總 |
| 勝負 | 先拉過勝利線者立即獲勝；時間到時，繩子偏向哪一側哪一側勝 |
| 平手 | 時間到時正好在 0 → 比總點擊次數 → 共通平手規則 |
| 加賽 | 繩子從目前位置繼續拉 3 秒 |
| 主螢幕 | 繩子即時位置（延遲 < 300 毫秒）、雙方點擊速度條 |
| 手機 | 整個畫面都是點擊區；繩子位置小圖 |

## 3. 拔劍決鬥（反應）

| 項目 | 規格 |
|---|---|
| 時間 | 最多 3 回合，約 11 秒 |
| 每回合 | 顯示「準備…」→ 隨機等待 1.5～4.0 秒（種子決定，所有人相同）→ 出現「拔劍！」→ 1.5 秒內點擊 |
| 反應時間 | 手機上「拔劍！」第一次被畫出那一幀的時間，到觸控事件的時間（本地計時，不受網路延遲影響） |
| 犯規 | 訊號出現前點擊＝這回合判負；所有人都犯規時重來一次，再犯規就算這回合沒有勝者 |
| 回合勝者 | 合法反應時間最短者；1.5 秒內沒點視為沒有成績 |
| 勝負 | 先拿到 2 回合者勝；3 回合後沒人拿到 2 勝 → 比勝場數 → 比合法回合的平均反應時間 |
| 1v1v1 | 同時比；排名依勝場數、再依平均反應時間（哈格拉茲要用第一名與最後一名） |
| 戰吼 | 反應時間以 −50 毫秒計算 |
| 平手 | 反應時間完全相同 → 共通平手規則 |
| 加賽 | 再一回合（等待 1.0～2.5 秒）；最快者勝 |
| 主螢幕 | 回合數、每回合誰最快與反應毫秒數 |

## 4. 符文辨識（反應）

| 項目 | 規格 |
|---|---|
| 時間 | 倒數期間顯示目標符文；對決約 9 秒 |
| 玩法 | 符文一個接一個閃過（共 16 個，每個 0.55 秒），其中 5 個是目標（種子決定位置，不會連續出現）；看到目標就點 |
| 計分 | 目標出現期間（含之後 0.25 秒）點擊 +1；點到非目標 −1；漏點 0；最低 0 分 |
| 干擾 | 非目標中混入外形相近的符文（例如目標 ᚠ 時混入 ᚨ、ᚱ） |
| 平手 | 比答對時的平均反應時間 → 共通平手規則 |
| 加賽 | 4 個符文快閃（每個 0.5 秒），其中 1 個是目標；先點對者勝，點錯直接判負 |
| 戰吼 | 分數 ×1.25（伺服器套用） |
| 主螢幕 | 目前的符文、雙方即時分數 |

## 5. 點酒單（記憶）

| 項目 | 規格 |
|---|---|
| 時間 | 主螢幕展示 4.5 秒＋手機輸入 7 秒 |
| 酒單 | 8 種酒（麥酒、蜂蜜酒、紅酒、蘋果酒、黑啤、白蘭地、苦艾酒、香料熱酒），每種有固定圖示與名稱 |
| 玩法 | **主螢幕**依序閃過 5 杯酒（不重複，每杯 0.9 秒）；之後手機出現 8 個酒的按鈕，照順序點 5 次 |
| 計分 | 位置完全正確的杯數（0～5） |
| 平手 | 比完成輸入的時間 → 共通平手規則 |
| 加賽 | 主螢幕展示 3 杯（2.7 秒）＋輸入 4 秒；比正確杯數，再比完成時間 |
| 戰吼 | 輸入期間可以按一次「再看一次」，在自己手機上重播酒單 2 秒（時間照走） |
| 主螢幕 | 展示酒單；輸入期間顯示雙方進度（只顯示點了幾杯，不顯示對錯） |
| ⚠️ | 酒單只在主螢幕展示（逼大家抬頭看電視）；如果座位離電視遠的人吃虧，改成手機也同步顯示 |

## 6. 鍛鐵（節奏）

| 項目 | 規格 |
|---|---|
| 時間 | 對決 10 秒 |
| 玩法 | 鐵鎚指針在橫條上來回擺動，點擊＝敲一下 |
| 擺動 | 來回一次 1.2 秒，每 3 秒加快 10%；起始相位由種子決定，所有人相同 |
| 判定 | 甜蜜點寬 12%（完美）；兩側各再 15%（良好）；其他＝失誤 |
| 冷卻 | 每次敲擊後 0.5 秒內不能再敲（防止亂點） |
| 計分 | 完美次數 |
| 平手 | 比良好次數 → 比失誤次數（少者勝）→ 共通平手規則 |
| 加賽 | 再敲 3 秒（擺動速度沿用最後的速度）；比完美次數，再比良好次數 |
| 戰吼 | 甜蜜點寬度 ×1.25（`myModifiers`；伺服器重算時也套用） |
| 主螢幕 | 雙方的鐵砧與每次敲擊的火花（完美／良好／失誤） |

## 7. 停錶（精準）

| 項目 | 規格 |
|---|---|
| 時間 | 最長 10 秒 |
| 玩法 | 計時器從 0.0 開始跑，**2 秒後隱藏**；在你覺得剛好 7.000 秒時按一次 |
| 計分 | 誤差＝｜按下時間 − 7000｜毫秒；10 秒內沒按，誤差記 3000 |
| 勝負 | 誤差小者勝 |
| 平手 | 誤差相同 → 共通平手規則 |
| 加賽 | 目標改成 3.000 秒，計時器 1 秒後隱藏 |
| 戰吼 | 誤差以 75% 計算 |
| 主螢幕 | 對決中只顯示「誰已經按了」；結束時揭曉雙方實際秒數 |

## 8. 符文猜拳（心理）

| 項目 | 規格 |
|---|---|
| 符文 | ᚲ 火 勝 ᛒ 樹（燃燒）；ᛒ 樹 勝 ᛚ 水（吸收）；ᛚ 水 勝 ᚲ 火（澆熄）。手機上永遠顯示這個循環圖 |
| 回合 | 3 回合，每回合：虛張聲勢 1.5 秒 → 出招 2.0 秒 → 揭曉 0.5 秒（約 12 秒） |
| 虛張聲勢 | 可以點一個符文「宣告」，會顯示在主螢幕上；宣告可以說謊，也可以不宣告 |
| 出招 | 選定的符文不公開，時間到同時揭曉；沒出招＝輸給有出招的人，雙方都沒出＝平手 |
| 計分 | 每回合勝 1 分、平手 0 分 |
| 勝負 | 3 回合後分數高者勝；同分 → 共通平手規則 |
| 加賽 | 第 4 回合（約 4 秒）；勝者勝 |
| 2v1 | 兩人各自出招，單人一方同時和兩人各比一次；每一組比較的勝者得 1 分；單人一方總分 ×1.5，和兩人總分比較 |
| 戰吼 | 平手的回合，你多算 0.5 分 |
| 主螢幕 | 雙方宣告、揭曉動畫、比分 |

## 9. 膽小鬼（心理）

| 項目 | 規格 |
|---|---|
| 時間 | 最長 10 秒 |
| 玩法 | 開始後 1 秒內雙方都要按住按鈕；池子持續累積（純演出）；**先放手的人輸** |
| 爆掉 | 爆掉的時間由種子決定，在 4.0～10.0 秒之間平均分布，不公開；爆掉時**還按著的人全部算輸** |
| 沒按住 | 開始 1 秒後還沒按住，視為 0 秒放手 |
| 雙方都輸 | 兩邊各自套用「落敗」的結果（例如防守方落敗受 10 傷害）；有押注的（給勃），押金歸系統 |
| 平手 | 兩人放手時間相差 ≤ 30 毫秒 → 共通平手規則 |
| 加賽 | 重新按住；爆掉時間改在 2.0～5.0 秒之間 |
| 戰吼 | 池子爆掉時你不算輸 |
| 主螢幕 | 不斷膨脹的金幣池、雙方手指是否還按著、爆炸或放手瞬間 |

## 10. 數金幣（速算）

| 項目 | 規格 |
|---|---|
| 時間 | 最長 10 秒 |
| 題目 | 畫面撒出 15～30 枚金幣（數量、大小三種、位置都由種子決定；互相重疊 ≤ 30%），全程可見 |
| 作答 | 數字鍵盤輸入後送出；答錯鎖定 1.5 秒 |
| 勝負 | 最先答對者勝；10 秒內都沒答對 → 最後一次答案最接近者勝 → 送出較早者勝 |
| 1v1v1 | 排名：答對者依答對時間；沒答對者依最後答案與正解的差距、再依送出時間 |
| 戰吼 | 第一次答錯不鎖定 |
| 平手 | 答對時間完全相同 → 共通平手規則 |
| 加賽 | 新題目 8～15 枚金幣，限時 5 秒；最先答對者勝 |
| 主螢幕 | 同一張金幣圖、誰已送出答案；結束時揭曉正確數量 |
