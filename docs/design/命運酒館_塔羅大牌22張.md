## 共通規則

| 項目 | 規則 |
|---|---|
| 取得 | 在神殿格抽到：從大牌牌庫（被持有的不在裡面）最上面最多 4 張牌背中**盲選 1 張**，在自己手機上**滑動掀開**（咪牌）；持有者知道是哪一張牌，也知道正位和逆位兩種效果；持有的大牌不公開，主螢幕只顯示「某某獲得一張大牌」與牌庫剩餘張數 |
| 正逆位 | **打出時才決定**正位或逆位（抉擇時刻），機率依打出者的醉意階段：清醒 正 70%／逆 30%；微醺 正 50%／逆 50%；爛醉 正 30%／逆 70%（暫定）；使用特定道具可以指定正逆位 |
| 反應牌 | 在別人的回合打出時，**直接以反應那一面發動**（目前惡魔、高塔都是逆位），不擲正逆位；在自己的回合打出時，才照醉意階段決定正逆位 |
| 使用 | 一律先保留在手上；在**自己的回合開始時或結束時**打出，每回合最多 1 張。標示「⚡ 反應」的牌可以在別人的回合打出 |
| 持續時間 | 標示「N 回合」的效果，從打出時算起，到所有人各行動 N 次為止；被暫停也算完成一次行動；額外移動不算行動；作用對象死亡時效果移除 |
| 名詞 | 「其他人」不包含持有者；「領先者」＝綜合資產（生命值 × 3＋金幣）第一的玩家；「最後一名」＝綜合資產最低的玩家 |
| 醉意階段 | 大牌的數值**不套用**全域 ±20%；正位寫明清醒與爛醉的變化；逆位用共通規則：清醒時對象由你指定，爛醉時對象改成隨機，而且可能包含你自己 |
| 回收 | 打出後**洗回牌庫的隨機位置**（2026-11-25） |
| 死亡 | 死亡時，手上的大牌洗回牌庫的隨機位置；唯一例外是「審判（正位）」可以在死亡當下立即發動 |
| 祭司大招 | 「命運之輪」翻開大牌牌庫最上面一張，由祭司當作自己打出（效果與一般版相同），是唯一不經手牌的方式 |
| 強度基準 | 一張大牌的價值，大約等於「一圈的收益」：約 30～60 金幣（依數值匯率：自己 1 血 ≈ 3 金幣、對一位對手 1 傷害 ≈ 1 金幣、1% 清醒值 ≈ 2 金幣），或一次直接改變勝負路線的機會 |

## 平衡檢查紀錄（v1 → v2）

> v2.2 確認：配合「打出時才決定正逆位」，v2 的共通規則全部保留。理由：翻到哪一面是運氣，持有者不應該因為翻到逆位而白白受害；風險改由醉意階段承擔（爛醉時逆位機率高，而且逆位對象可能包含自己）。


| 問題 | v1 的牌 | v2 的處理 |
|---|---|---|
| 「本周」長度不固定（7～16 回合），價值不穩定，而且可以挑星座剛切換時打出 | 大多數持續型效果 | 全部改成固定「5 回合」（v2.2 由 3 回合改為 5 回合）；封鎖型（荒蕪、黯淡、日蝕）v2.4 改為 3 回合 |
| 全域負面效果連持有者自己也受害，持有者沒有理由打出 | 荒蕪、厄運、日蝕、黯淡、縱慾、天崩 | 改成只影響「其他人」，或讓持有者得利 |
| 全場都受益，持有者沒有相對優勢 | 女皇、節制、太陽 | 改成以持有者為主的效果 |
| 效果太弱或沒有實際作用 | 月亮（格子在 28 格地圖上很容易記住）、吊人、惡魔、愚者逆位 | 重新設計 |
| 超標 | 戰車（整周每次都能選格）、命運之輪（金幣無上限交換）、死神（直接擊殺）、審判逆位（整周零魂火）、隱士（自選任意位置） | 設上限或改成有條件 |
| 反制牌沒有邊界 | 高塔逆位（可以取消任何效果） | 只能取消「針對你」的效果，不能取消勝利條件與星座 |
| 名詞模糊 | 「排名最後」「本周」「其他人」 | 在共通規則中定義 |

| 牌 | 選用理由 |
