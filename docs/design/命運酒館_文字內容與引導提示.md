# 命運酒館｜文字內容與新手引導提示 v1.0

> 更新日期：2026-11-25（v1.0：定案）
> 範圍：MVP 所有顯示文字的寫法規則、文字清單（要寫幾條、寫在哪），以及引導模式的提示清單與初稿。
> 依據：《設定總表》§1「新手教學」（引導模式：只在本人手機、第一次遇到才出現、不簡化規則、只說明不推薦）、《MVP卡牌v4》§0 固定用詞、《畫面清單》、《訊息格式》§14。
> 所有文字走語系檔（`packages/i18n/zh-TW.json`）；本文件的文字是初稿，數值一律以設計文件為準。⚠️ ＝待確認。

## 1. 寫法規則

| 項目 | 規則 |
|---|---|
| 語言 | 繁體中文；數字用阿拉伯數字；單位緊跟數字（10 金幣、3 杯、5 回合） |
| 固定用詞 | 照《MVP卡牌v4》§0：得／失去金幣、給、回血、扣血、受傷害、喝、清醒值、魂火、移動、瞬移、入獄、得到道具、交出、棄、偷看、攻防、擲 D8、選擇、投票、下注、狀態。同一件事只用一個詞 |
| 主螢幕 | 只寫結果，格式「誰＋變化」，例如「阿哲 −10 血」「其他人各喝 1 杯」；**一行 ≤ 18 字** |
| 手機按鈕 | ≤ 6 字，用動詞開頭（「擲骰」「不使用」「出價 +20」） |
| 手機卡牌說明 | 每個版本 ≤ 60 字；先寫效果，再寫條件 |
| 引導提示 | 標題 ≤ 10 字＋內文 ≤ 2 行（約 40 字）；只說規則與選項效果，**不說「建議你…」** |
| 錯誤訊息 | 說「發生了什麼＋現在可以做什麼」，不出現錯誤代碼（代碼只進日誌） |
| 語氣 | 規則、提示、錯誤訊息用中性簡短的說明文字；卡名、牌意、結算標題可以帶酒館氣氛（2026-11-25 確認） |
| 語系鍵 | `分類.ID.欄位`，例如 `card.minor.swords.10.upright.tipsy`、`guide.first_drink.body`、`error.not_your_turn` |

## 4. 引導提示清單與初稿

> 規則：每位玩家**第一次遇到**該機制時，在本人手機上出現一次；可以點「知道了」或滑掉，不擋操作；引導模式關閉時都不出現。

| G02 | 第一次輪到你 | 輪到你了 | 擲 D8 前進。經過起點得 30 金幣；停下的格子會觸發事件。 |

## 5. 錯誤與系統訊息（節錄）

| 代碼 | 手機顯示 |
|---|---|
| `not_your_turn` | 還沒輪到你，等一下喔。 |
| `insufficient_resource` | 金幣（或清醒值）不夠。 |
| `on_cooldown` | 技能冷卻中，還要 {n} 回合。 |
| `limit_reached` | 這次已經用過了。 |
| `prompt_expired` | 時間到了，已自動選擇預設選項。 |
| `game_paused` | 對局暫停中。 |
| `dead_player_restricted` | 死神追逐中不能這樣做。 |
| 斷線重連中 | 連線中斷，正在重新連線… |
| 主螢幕斷線 | 主螢幕斷線，對局暫停。 |
| 代打 | 你斷線了，暫時由電腦代打；重新連上就交還給你。 |

## 6. 引導紀錄存在哪裡

- MVP 沒有帳號系統，「看過哪些提示」存在**手機瀏覽器**（localStorage），依裝置記錄；換手機或清除資料會重新出現（2026-11-25 確認）。
