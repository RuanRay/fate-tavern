## 1. 基本規則

| 項目 | 規則 |
|---|---|
| 抽取處 | **酒館格**（4 人局 28 格中佔 11 格，約 40%） |
| 牌庫 | 四種花色混在一起；**有限牌庫**：開局洗好，抽過不放回，抽完把棄牌堆重洗（2026-11-25）；主螢幕只顯示剩餘張數 |
| 抽牌方式 | 抽牌者手機攤開牌庫最上面 4 張牌背，**盲選 1 張**；選定後才決定正逆位（完整規則見《設定總表》第 5 節「牌庫與抽牌」） |
| 結算 | 抽到後**當下決定正逆位並結算**；只有持有特殊道具（或巨蟹座「月下藏寶」那一周）才能保留 |
| 回收 | 結算完進棄牌堆；同一輪內不會再抽到同一張 |
| 保留的小牌 | 不公開，只在自己的手機上看得到；保留時還沒決定正逆位，打出時才決定 |
| 相關角色技能 | 祭司小技能可以重抽一張小牌：原本那張放回牌庫最底部，再盲選 1 張，重新決定正逆位；遊俠大招「鷹眼」直接翻開牌庫最上面 3 張選 1（其餘放回最底部，選定後才決定正逆位） |
| 相關星座 | 雙子座「雙重命運」：盲選 2 張牌背、翻開後選 1 張，另一張放回最底部；巨蟹座「月下藏寶」：可以保留 1 張小牌 |
| 死亡玩家 | 停在酒館時不抽小牌，改抽「冥界事件」（見第 8 節） |

### 名詞與共通規則

| 名詞 | 定義 |
|---|---|
| **手牌** | 小牌事件裡的「手牌」＝**道具＋魔術骰子**。塔羅大牌、保留的小牌、冥火骰都**不算**手牌，不會被偷、被棄；只有寫明「大牌」的事件才能碰到大牌 |
| **偷看／揭露** | 一律**只給抽牌者看**（在抽牌者的手機上顯示）；主螢幕只顯示「某某偷看了某某」，不顯示內容 |
| **擲骰** | 小牌事件裡的 D8 都是玩家自己擲的骰，**可以使用魔術骰子**（包含別人對你的骰子使用）；寫明「系統隨機」的不行 |
| **持續時間** | 一律寫成「N 回合」（從抽到時算起，到所有人各行動 N 次為止）或「N 次行動」（只算自己的行動） |
| **攻防** | 小牌觸發的攻防，照第 7 節指定的小遊戲進行；傷害、道具、加成規則跟試煉卡一樣 |
| **優先配對對手** | 在試煉之地隨機配對時優先被選中；順序排在技能、佔位對決、死亡玩家之後 |
| **沒有手牌時**（2026-11-24 確認） | 偷、棄、交出手牌的效果，遇到該交出的人沒有手牌時，**每 1 張改成 20 金幣**；金幣也不夠就拿到多少算多少（不會負債）。例：寶劍七偷到沒有手牌的人 → 改拿他 20 金幣；聖杯七沒有手牌可棄 → 改失去 20 金幣 |
| **碰到**（2026-11-24 確認） | 「途中碰到的第一位玩家」＝移動時**經過或停在**同一格的第一位玩家（判定方式與惡靈作祟相同）；不含出發格上的人 |
| **寫法規則**（v4） | MVP 20 張依《命運酒館_MVP卡牌v4》第 0 節：最多 2 個效果、醉意版只改一處、「受傷害」走傷害管線、「扣血」是代價；效果全部由效果元件表達 |

## 2. 設計規則與比例目標

- 正式版做滿 **56 張**（四種花色 × 14 張），每張都有正位和逆位；MVP 從中挑出 20 張。
- 事件依照每張牌的**經典牌意**（萊德偉特體系）設計：正位用正位牌意，逆位用逆位牌意。
- **花色對應元素方向**（寶劍與權杖已依牌面印象對調）：

| 花色 | 方向 | 主題 |
|---|---|---|
| ⚔️ 寶劍 | 戰鬥 | 衝突、真相、決斷 |
| 🪄 權杖 | 運氣 | 熱情、行動、冒險 |
| 🏆 聖杯 | 計謀 | 情感、人際、直覺 |
| 🪙 錢幣 | 經濟 | 財富、工作、物質 |

- **數值校正目標**（換算成金幣）：好事件約 **+20～30**、壞事件約 **−20～30**、取捨事件期望值約 **0 ±10**。
- **數值匯率**（見《命運酒館_設定總表》第 4 節）：自己 1 血 ≈ 3 金幣、對一位對手 1 傷害 ≈ 1 金幣、1% 清醒值 ≈ 2 金幣、喝 1 杯 ≈ 6 金幣、1 次行動 ≈ 10 金幣、1 格 ≈ 2 金幣、1 張手牌 ≈ 20 金幣、1 顆常見魔術骰子 ≈ 10 金幣。
- 數值尺度：起點收入 30 金幣、基礎傷害 10、喝一杯清醒值 −3%。

| 比例目標 | 數值 |
|---|---|
| 好 : 壞 : 取捨（正逆合計） | 約 3 : 3 : 4 |
| 正位 | 偏好事件 |
| 逆位 | 偏壞事件，但約 1/3 是高風險高報酬的爆發事件 |
| 帶到喝酒 | 約 3/5 |
| 只影響自己 : 牽涉其他玩家 | 約 3/7 : 4/7 |
| 每張喝幾杯 | 大多 1～2 杯，少數由 D8 決定 |

- 實際統計見第 4、5 節開頭。

## 3. 正逆位與醉意階段

### 正逆位的決定

抽到時（或打出保留的小牌時）依抽牌者當下的醉意階段決定，跟塔羅大牌相同：

| 階段 | 正位 | 逆位 |
|---|---|---|
| 清醒（100～71%） | 70% | 30% |
| 微醺（70～51%） | 50% | 50% |
| 爛醉（50～0%） | 30% | 70% |

- 這是系統隨機，**不能**用魔術骰子改動。
- 效果：越醉越容易抽到逆位（偏壞、但有爆發）；清醒的人比較能拿到穩定的好事件。

### 醉意階段的數值

| 階段 | 全域效果 |
|---|---|
| 清醒 | 正面效果 +20%、負面效果 −20% |
| 微醺 | 不變（卡牌的「基本效果」） |
| 爛醉 | 正面效果 −20%、負面效果 +20% |

- **MVP 20 張**：正位、逆位都有清醒、微醺、爛醉三種版本（第 6 節）；卡牌寫明的階段效果優先，數字為最終值，不再疊加全域 ±20%。
- **其餘 36 張**：只有正位、逆位的基本效果，醉意階段套用全域 ±20%；但**逆位在爛醉時不疊加「負面 +20%」**，避免和「爛醉逆位 70%」雙重懲罰。
- 喝酒杯數不算負面效果，不受階段影響。
- 設計方向：清醒＝更精準、更可控；爛醉＝失控但有爆發性的報酬。
