## 1. 遊戲分級（遊戲軟體分級管理辦法）

| 項目 | 查到的規定 | 對本作的影響 |
|---|---|---|
| 分級 | 限制級、輔導十五歲級、輔導十二歲級、保護級、普遍級 | — |
| 輔導十五歲級 | 含「引誘使用菸酒的畫面或情節」；或使用虛擬遊戲幣、結果直接影響遊戲幣增減的牌類及益智娛樂遊戲 | 本作以喝酒為核心、賭場用遊戲金幣下注 → **法規最低至少輔十五** |
| 限制級 | 條文列的是色情、血腥殘虐、毒品、自殺自傷等，未列菸酒 | 本作內容本身不一定落入限制級 |
| 牌類遊戲的警語 | 以牌類及益智娛樂類為主要情節者，要標示不得利用遊戲賭博的警語 | 賭場是格子之一，不是主要情節；保守起見仍標示 ⚠️ |
| 標示義務 | 上市前自行分級；在下載頁面標示分級標識、情節名稱（三種以上至少標三種）、注意遊戲時間與避免沉迷等警語；限制級要標示滿十八歲才能購買或使用 | 下載頁、主螢幕開機畫面都要標 |
| 資料庫登錄 | 發行或代理者在上市前，把級別、情節與聯絡資料登錄到主管機關資料庫 | 公開前完成 |
| 主管機關 | 遊戲軟體分級事項自 2022-08-27 起由數位發展部管轄 | — |

**建議**：雖然法規最低是輔十五，但本作會**提示玩家現實喝酒**，而未滿 18 歲不得飲酒，所以**自評限制級**，和遊戲內的 18 歲確認一致（2026-11-25 確認）。

## 2. 未成年人不得飲酒（兒童及少年福利與權益保障法）

- 兒少法第 43 條：兒童及少年（未滿 18 歲）不得飲酒；任何人不得販賣、交付或供應酒給兒少。
- 本作做法：
  - 主螢幕與手機首次開啟都有 18 歲確認（已在畫面清單 H00、P00）。
  - 灰盒測試現場由主持人確認年齡（灰盒測試計畫 §2）。
  - 非酒精版 DLC 是未來給其他年齡層的版本（目前 MVP 之後）。

## 3. 酒類廣告（菸酒管理法）

- 查到的條文（第 37 條）：**酒之廣告或促銷**要明顯標示「飲酒過量，有害健康」或其他警語，並且不得鼓勵或提倡飲酒、不得妨害青少年身心健康等；違反可處 10 萬～50 萬元罰鍰。施行細則把「廣告」定義為可使不特定多數人知悉其宣傳內容的傳播。
- 本作本身不是酒類商品，但下列情況可能被認定為酒的廣告或促銷 ⚠️：
  - 遊戲內出現**真實酒類品牌**（目前沒有：點酒單用的是麥酒、蜂蜜酒等一般名稱）。
  - 和酒商合作、贊助、聯名。
  - 宣傳素材呈現大量飲酒或鼓勵喝酒。
- 建議：
  - 遊戲內、宣傳素材**不使用真實酒類品牌**。
  - 宣傳素材與開場畫面加上「飲酒過量，有害健康」警語（預防性做法）。
  - 宣傳強調「派對與策略」，不以「喝很多」當賣點。
  - 任何酒商合作，先請律師確認。

## 4. 平台

| 平台 | 查到的規定 | 對本作的影響 |
|---|---|---|
| Steam（主螢幕 PC 版的可能通路） | 上架前要完成內容問卷，揭露玩家可能遇到的成熟內容；Valve 會比對問卷與實際內容 | 要在問卷與商店頁揭露「現實飲酒」；沒查到明確禁止飲酒遊戲的條款 ⚠️ |
| Apple App Store | 審查準則 1.4.3：鼓勵消費菸草、非法藥物或**過量酒精**的 App 不得上架；開發者論壇有飲酒遊戲 App 被退件的案例 | **手機控制器維持網頁版**（不上 App Store），避開這條；若之後要包成 App，酒精版風險很高，改用非酒精版 |
| Google Play | 本次未查證 ⚠️ | 包成 Android App 前再查 |
| 手機網頁 | 不經商店審查 | 照台灣法規與本作自己的年齡確認 |

## 5. 個人資料（個人資料保護法）

- 個資法第 8 條：向當事人蒐集個人資料時，要告知：蒐集者名稱、目的、資料類別、利用的期間、地區、對象與方式、當事人的權利與行使方式、不提供的影響。
- 本作蒐集的資料：

| 資料 | 是否識別個人 | 做法 |
|---|---|---|
| 暱稱 | 可能（玩家自己取） | 提示「不要用真實姓名」；只存在對局紀錄 |
| 匿名玩家 ID、Session Token | 不直接識別 | Token 只存雜湊（已在 M0） |
| 遊戲事件與遙測（含喝酒杯數、確認率） | 和暱稱結合時可能間接識別 | 匯出時只用匿名 ID；喝酒數據只做統計 |
| IP 位址（伺服器日誌） | 可能 | 日誌保存 30 天 |
| 錯誤追蹤（Sentry，選配） | — | 清除 Token 與玩家輸入（已在 M8-R15） |

- 建議：
  - 加入頁（P01）放**隱私告知**（照第 8 條六項），加入即視為已閱讀。
  - 對局資料保存 1 年，之後只留匿名統計。
  - 提供刪除請求的聯絡方式。

## 6. 使用條款與遊戲內警語

| 項目 | 內容 |
|---|---|
| 年齡 | 18 歲以上才能使用酒精版 |
| 健康警語 | 開場（H00、P00）顯示「飲酒過量，有害健康」與「請勿酒後駕車」；說明可以隨時開啟「不喝酒」開關 |
| 責任 | 現實飲酒由玩家自行決定與負責；遊戲數值不要求現實真的喝 |
| 收費 | MVP 免費、無帳號；之後若收費或開帳號，要另外檢視「網路連線遊戲服務定型化契約應記載及不得記載事項」⚠️ |
