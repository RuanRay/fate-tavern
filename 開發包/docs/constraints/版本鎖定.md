# 版本鎖定

> M0 開工第一天由 A 角色填寫實際版本並提交；之後升級主版本要開 ADR，在獨立分支驗證。
> 原則：選**當下的穩定版／LTS**，鎖到小版本；不追最新的預覽版。

| 工具 | 鎖定方式 | 版本（M0 填寫） | 備註 |
|---|---|---|---|
| Node.js | `.nvmrc`＋`package.json` `engines` | ⚠️ 當下的 Active LTS（偶數版號） | CI 與 Docker 映像同一版本 |
| pnpm | `package.json` `packageManager` | ⚠️ | 用 Corepack 啟用 |
| TypeScript | `devDependencies` 固定版本 | ⚠️ | — |
| Fastify | 固定主版本 | ⚠️ | 外掛版本要跟主版本相容 |
| ws | 固定主版本 | ⚠️ | — |
| Zod | 固定主版本 | ⚠️ | 主版本升級會影響 JSON Schema 產生 |
| Drizzle ORM／Kit | 固定版本 | ⚠️ | Migration 產生器版本變動要重新檢查輸出 |
| React／Vite | 固定主版本 | ⚠️ | — |
| PixiJS | 固定主版本 | ⚠️ | 手機小遊戲 |
| Vitest／fast-check／Playwright | 固定版本 | ⚠️ | — |
| PostgreSQL | Docker 映像 tag（含小版本） | ⚠️ 當下的穩定主版本 | 本機與託管同一主版本 |
| Godot | 專案設定與 CI 匯出模板 | ⚠️ 當下的 Godot 4 穩定版（例如 4.x.y） | 只用標準版（非 .NET 版） |
| GUT | 固定版本 | ⚠️ | 要支援鎖定的 Godot 版本 |
| mkcert | 開發工具，README 記版本 | ⚠️ | 本機 HTTPS 憑證（技術規劃 §7-1） |
| cloudflared | 開發工具，README 記版本 | ⚠️ | 備用：暫時的 HTTPS 網址 |

## 測試硬體（M0 填寫，技術規劃 §7-1）

| # | 裝置 | 型號 | 系統版本 | 負責人 |
|---|---|---|---|---|
| W1 | 你的筆電（開發兼主螢幕測試） | i7-12650H、RTX 4060 Laptop GPU、16 GB | Windows（M0 填版本） | 你 |
| M1 | iPhone 13 | iPhone 13 | M0 填 iOS 版本 | 你 |
| — | Android | 灰盒測試時借測試者手機；平時用 Chrome DevTools 模擬 | — | 你 |

> **2026-11-25**：只有這兩台裝置。**不做低規格 Windows 測試**（已知風險：內顯電腦可能掉幀，灰盒時若有人用內顯電腦當主螢幕，記錄幀率）。原本的 W1 低規格機、M2 舊 iPhone、M3／M4 Android 取消；Android 相容問題在灰盒第 1 輪集中修。

## 升級規則

1. 開 ADR：為什麼升、影響範圍、回退方式。
2. 獨立分支升級，跑完整 CI＋黃金重播＋崩潰恢復。
3. Godot 升級另外檢查：場景、Shader、匯出、GUT、3D 骰子軌跡播放。
4. 不在里程碑最後一週升級。
