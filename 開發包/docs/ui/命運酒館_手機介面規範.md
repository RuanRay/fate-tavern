# 命運酒館｜手機介面規範（第一階段）v1.0

> 更新日期：2026-11-25（v1.0：定案，確認紀錄見第 7 節）
> 用途：第一階段手機控制器（`apps/mobile-web`）的**暫用設計規範**：設計代號（顏色、字、間距）、元件、版面、狀態。AI 實作手機畫面時照本規範，不自己發明樣式。
> 為什麼需要：手機在 M0 就要開始做，但小黃的風格切片要到約 2027-05-25 才完成；正式的手機 UI 元件（美術清單 A22）由小黃之後提供。
> 依據：《畫面清單》v1.6 §0、§3、《文字版主螢幕》v1.0、《美術與音效清單》v1.2、《文字內容與引導提示》§1、《技術限制》§1。

---

## 0. 原則

| # | 原則 |
|---|---|
| U-1 | **元件只讀設計代號**（CSS 變數），不寫死顏色、字級、間距；小黃交正式版時只換代號值與少數元件外觀，畫面邏輯不動 |
| U-2 | 直式、單手；主要按鈕在畫面下半部、拇指範圍內 |
| U-3 | 喝醉也看得懂：大字、高對比、一個畫面只問一件事 |
| U-4 | 不只靠顏色：玩家用「顏色＋符號（●▲■◆）」，狀態用「圖示或文字＋顏色」 |
| U-5 | 手機只顯示**自己的**數值（畫面清單 U3）；選目標時才顯示候選人做決定需要的那一項 |
| U-6 | 樣式用 **CSS Modules＋CSS 變數**（設計代號）；不用 Tailwind 或大型 UI 套件；首次載入 JS 壓縮後 < 500 KB（技術限制 §1），小遊戲的 PixiJS 只在小遊戲時才載入 |

## 1. 設計代號（暫用值）

**顏色**：**暗色與淺色兩組，跟著手機系統設定切換**（`prefers-color-scheme`；U3）。暖色調的酒館氛圍；對比度 ≥ 4.5:1。

| 代號 | 用途 | 暗色暫用值 | 淺色暫用值 |
|---|---|---|---|
| `--color-bg` | 背景 | `#1E1A17` | `#F7F1E8` |
| `--color-surface` | 卡片、底部面板 | `#2B2521` | `#FFFDF9` |
| `--color-surface-raised` | 浮起的面板、輸入請求 | `#3A322C` | `#EDE3D6` |
| `--color-text` | 主要文字 | `#F3EADF` | `#2A211B` |
| `--color-text-muted` | 次要文字 | `#BFB2A3` | `#5E5146` |
| `--color-primary` | 主要按鈕、選中 | `#E0A43A`（琥珀） | `#8A5004` |
| `--color-on-primary` | 主要按鈕上的字 | `#1E1A17` | `#FFFFFF` |
| `--color-danger` | 危險、扣血、倒數快結束 | `#F28B80` | `#B3261E` |
| `--color-success` | 得到、成功 | `#7CC28A` | `#256B33` |
| `--color-info` | 提示、引導 | `#7FB2E0` | `#1F5E99` |
| `--color-hp` / `--color-gold` / `--color-clarity` / `--color-soul` | 資源 | `#F28B80` / `#E0C24A` / `#7FB2E0` / `#B48CE0` | `#B3261E` / `#7A5C00` / `#1F5E99` / `#6B3FA0` |
| `--color-player-1`～`4` | 玩家色（搭配符號 ●▲■◆） | `#EE9278` ● / `#81B29A` ▲ / `#7FA6E0` ■ / `#D9A6E0` ◆ | `#A23E26` ● / `#2F6B4F` ▲ / `#2B5C9E` ■ / `#863A98` ◆ |
| `--color-tier-sober` / `-tipsy` / `-drunk` | 醉意階段 | `#7CC28A` / `#E0C24A` / `#F28B80` | `#256B33` / `#7A5C00` / `#B3261E` |

- 玩家色與符號和文字版主螢幕一致（文字版主螢幕 §0）。
- 暫用值已檢查：兩組顏色中，所有文字色與資源色在三種底色（`bg`、`surface`、`surface-raised`）上對比度都 ≥ 4.5:1（暗色 ≥ 5:1）；主要按鈕上的字：暗色 7.9:1、淺色 6.5:1。
- 文字版主螢幕（電視）固定用暗色，不跟系統切換。

**字**

| 代號 | 值 |
|---|---|
| `--font-body` | Noto Sans TC（SIL OFL；子集化後自架），系統字型為後備 |
| `--font-size-body` / `--font-size-button` / `--font-size-title` / `--font-size-number` | 16px / 18px / 22px / 28px |
| `--font-size-hero` | 48px（擲骰結果、倒數秒數） |
| `--font-weight-regular` / `--font-weight-bold` | 400 / 700 |

**間距、圓角、尺寸**

| 代號 | 值 |
|---|---|
| `--space-1`～`--space-6` | 4 / 8 / 12 / 16 / 24 / 32 px |
| `--radius-s` / `--radius-m` / `--radius-l` | 6 / 12 / 20 px |
| `--touch-min` | 48px（所有可點的東西） |
| `--button-main-height` | 56px |
| `--safe-top` / `--safe-bottom` | `env(safe-area-inset-top)` / `env(safe-area-inset-bottom)` |

**動態**

| 代號 | 值 |
|---|---|
| `--motion-fast` / `--motion-normal` | 120ms / 240ms |
| 減少動態 | 系統開啟「減少動態效果」時，所有轉場改成淡入、不位移 |

## 2. 版面

```
┌───────────────────────────┐ ← safe-top
│ 狀態列：● 阿哲｜聖殿騎士      │  生命 92/110・金幣 75・清醒 64%（微醺）
│        狀態標籤（中毒 1・剩 2） │
├───────────────────────────┤
│                           │
│ 主要區：                    │  待機：「等待 ▲ 小美」＋星座摘要
│  依畫面不同                 │  輪到我：大擲骰按鈕
│                           │
├───────────────────────────┤
│ 動作列：手牌｜技能｜規則｜設定  │  底部分頁（48px）
└───────────────────────────┘ ← safe-bottom
```

- **輸入請求**（P05～P13、P33）一律用**底部面板**蓋在當下畫面上，高度依內容（最多 85%）；上方保留狀態列看得到自己的數值。
- 倒數條固定在底部面板最上緣；剩 3 秒時變 `--color-danger`，並震動一次（Android；iOS Safari 不支援震動，改用畫面閃爍）。
- 小遊戲（P24）全螢幕，蓋掉狀態列與動作列。

## 3. 元件

| 元件 | 用途 | 狀態 |
|---|---|---|
| `Button` | 主要／次要／危險三種 | 一般、按下、停用、載入中（送出後等伺服器回覆） |
| `OptionCard` | 選項卡（含結果預覽一行） | 一般、選中、停用、預設（標「時間到自動選」） |
| `PlayerChip` | 選目標用：顏色＋符號＋暱稱＋需要的那一項數值 | 一般、選中、不可選（灰＋原因） |
| `ResourceStat` | 生命、金幣、清醒、魂火（圖示＋數字＋變化飄字） | 一般、增加（綠閃）、減少（紅閃） |
| `TierBadge` | 醉意階段 | 清醒／微醺／爛醉 |
| `StatusTag` | 狀態標籤（文字＋剩餘） | — |
| `CountdownBar` | 伺服器時間換算的倒數 | 一般、快結束、已截止 |
| `BottomSheet` | 輸入請求容器 | 開、關、被新請求取代 |
| `CardView` | 文字卡（卡名、正逆位、醉意版本、效果文字、這次結果） | 正位、逆位 |
| `CardBack` | 盲選牌背（P33） | 一般、選中、翻開 |
| `ItemRow` | 手牌道具與骰子 | 可用、不可用（附原因）、使用中 |
| `NumberPad` | 數金幣、押注金額 | — |
| `Toast` | 一行系統訊息（照文字內容 §5） | 資訊、錯誤 |
| `Banner` | 置頂橫幅（暫停、斷線、代打中） | — |

- 每個元件放 `apps/mobile-web/src/ui/`，各有一個用假資料的展示頁（`/dev/ui`，只在開發環境），方便你和小黃看所有狀態。

## 5. 驗收

| # | 條件 |
|---|---|
| UI-A01 | 元件與畫面沒有寫死的顏色、字級、間距（lint：禁止 CSS 裡出現色碼與 px 字級，設計代號檔除外） |
| UI-A02 | iPhone 13（Safari）與 Chrome DevTools 模擬 360 寬的 Android：所有第一階段畫面沒有被裁切、按鈕 ≥ 48px |
| UI-A03 | 對比度檢查：暗色、淺色兩組，文字與背景都 ≥ 4.5:1（自動化檢查設計代號組合） |
| UI-A04 | 手機系統切換暗色／淺色時，所有畫面即時跟著切換，沒有看不見的文字或圖示 |
| UI-A05 | 首次載入 JS 壓縮後 < 500 KB（不含小遊戲） |

## 6. 小黃接手

- 風格切片完成後（約 2027-05-25），小黃依本規範第 1、3 節提供正式版：**暗色與淺色兩組**設計代號值、元件外觀（可以是 Figma 或圖片標註）、圖示。
- 你（或 AI）把正式值換進設計代號檔、調整元件外觀；**畫面結構與流程不改**。之後的新畫面直接用正式版。
- 圖示：第一階段用文字與 Unicode 符號；正式圖示（美術清單 A12～A17）由小黃交付後替換。
