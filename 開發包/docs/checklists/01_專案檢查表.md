## 3. 核心概念（G1）

**一句話**：玩家是命運酒館裡的冒險者，透過擲骰移動、抽塔羅與盧恩牌觸發事件、用手機小遊戲決鬥、喝酒換取風險與報酬，達成「拍下聖物繞完一圈」或「最後存活」。本作的特色是**電視＋手機的非對稱派對體驗，加上醉意本身就是遊戲數值**。

| 項目 | 內容 |
|---|---|
| 玩家扮演 | 6 種職業之一（聖殿騎士、魔法師、遊俠、商人、賭徒、祭司） |
| 反覆進行的行動 | 擲骰 → 移動 → 觸發格子事件（抽牌、決鬥、購物、拍賣、賭場、祭壇）→ 選擇與互動 |
| 最有特色的地方 | 清醒值＝醉意：越醉越容易抽到逆位（爆發或倒楣）；喝酒是代價、懲罰也是資源 |
| 主要輸入方式 | 手機觸控（直式、單手、大按鈕） |
| 單機／多人 | 同一個客廳的多人（每人一支手機）；伺服器在雲端，架構預留異地遊玩 |

**參考遊戲**（2026-11-25 確認）

| 參考遊戲 | 參考項目 | 本作差異 |
|---|---|---|
| Mario Party | 棋盤移動＋小遊戲 | 小遊戲只用在攻防、約 15 秒；有正式的經濟與勝利路線；成人向、喝酒系統 |
| Jackbox Party Pack | 電視＋手機的派對形式 | 本作是一局 2.5 小時的完整策略遊戲，不是短局問答 |
| 桃太郎電鐵 | 一局很長的棋盤遊戲；追趕機制；黏著落後者的負面角色（窮神） | 用來對照「長局是否撐得住」與死神追逐的壓力設計；本作有直接對打與喝酒 |
| Dokapon Kingdom | 棋盤上直接對打、互相陷害、一局數小時 | 最接近本作「競技＋惡意互動」的參考；本作沒有 RPG 成長、改用醉意與塔羅 |

- 原本列的大富翁／いただきストリート移除：本作沒有地產，相似處只剩繞圈。

**核心循環檢查**

- [x] 每輪都有風險與收益（喝酒換報酬、逆位爆發）
- [x] 至少兩種可行策略（經濟勝利／血量勝利；6 職業偏向不同）
- [ ] 玩家是否「知道現在要做什麼」：由 M2 灰盒試玩驗證
- [ ] 2.5 小時是否值得：⚠️ M2 灰盒試玩只有部分機制，完整時長要到 M8 灰盒版才能驗證（2026-11-25 取消紙本試玩後的已知風險）

**灰盒原型試玩**

- 時間點：M2 結束（約 2027-02 初），用文字版假主螢幕＋手機＋規則核心，只有擲骰、移動、酒館小牌、清醒值。
- 至少 5 位沒參與開發的人；不逐步解說；記錄：第一次卡住的地方、誤解的規則、每個人覺得最有趣與最無聊的格子。
- 三人以上在同一處卡住就優先修改；不要只問「好不好玩」。
- 試玩紀錄模板：測試日期、版本、人數、第一次卡住位置、最常見誤解、最受歡迎、最無趣、下一步修改。

## 10. 核心原則

一個功能完成，不代表程式存在。它必須：可以操作、可以理解、可以測試、可以重播、可以在崩潰後恢復、可以在正式建置與目標硬體上運作、可以安全修改與回退、不會破壞其他系統。
